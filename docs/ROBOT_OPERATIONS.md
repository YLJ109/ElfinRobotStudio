# 机器人操作指南：可以做、不能做与验收

**这不是厂家操作手册，不是安全认证，也不是授权书。** 当前控制源码和离线证据不能证明现场可用；操作人必须遵守厂家/场地规程、实体保护和工具要求。本文不给未知控制器编造参数。

## 能力分级

| 层级 | 可以做 | 不可以推导 |
| --- | --- | --- |
| 离线 | 阅读代码、仿真、隔离假设备测试 | 现场安全或相同轨迹 |
| 明确授权的只读连接 | 身份、状态、版本、关节/PCS和IO回读 | 可以使能、试阀、运动 |
| 经现场确认的有限运动 | 对已资格适配器、工具和范围低速验收 | 原生直线/Servo也自动获资格 |
| 持续跟随/任务 | 只对已绑定版本与工具且通过现场验证的功能开放 | 通用可运行、自动恢复或跨设备复用许可 |

## 操作前核对

- 当前用户/现场操作者明确同意哪类动作；历史“允许连接”不等于允许运动。
- 真实机型、固件、协议与命令/反馈通道身份，不拿SDK版本代控制器版本。
- 实际安装工具、TCP、负载、包络、吸盘气路与反馈；外观模型不证明已标定。
- 现场无人处于危险范围、物理急停及保护可用；具体检查依现场规程。
- 新鲜同连接状态、明确故障/使能/倍率/停稳，未知不能补零或当正常。
- 计划绑定起点/场景/工具/连接/配置，没有其他程序、跟随或手拖占用。
- 停止和失败恢复已确认；没有现场记录时保留门禁。

## 真机笛卡尔与跟随

当前笛卡尔输入经IK得到关节目标，真机默认MoveRelJ逐轴逼近；不是TCP直线保证。原生MOVEL尚未通过当前资格，不能自行改命令名解除限制。
新跟随宿主已接入生产源码：主动启动后受控去中心、J6目标0、实际到位，再由新鲜手掌控制位置。缺资格仍应拒绝启动。
J6=0是此跟随策略，不强加给所有六自由度点位。丢掌/异常停止且手动重启，不能套用仿真回中心。
本轮已知稳定保持误过期、调度与停止证明问题仍未修，不能据此开始现场跟随。

## 双吸盘和IO

左右各有吸气、停止吸气、破真空、停止破真空的规划，共八个业务操作，不等于DO1至DO8。
只有实际映射/有效电平/互斥顺序/反馈/保持策略确认后才能试动作；输入DI只读，禁止盲扫输出。
ACK或DO回读不等于吸牢；无真空传感器应标吸附未验证。停止运动不默认关气或破真空；断线/急停/掉电的物理保持能力须核验。
现场试阀需独立授权并按工件与危险范围管理，不能用标定向导对未知通道试全遍。

## 停止与异常

- 发出软件停止后先撤销新输入，等待控制器回执和原连接新鲜静止证据。
- “停止待确认/未知”不能改成已停稳；保持追加动作闭锁，按现场规程处理。
- 网络断开、程序退出或刷新不等于物理制动；软件停止不能替代物理急停。
- 不盲重试可能已经发出的运动/IO，不在新连接重放旧命令。
- 故障解释和AI建议仅作排查参考，不能代替厂家故障处置。
- 当前Esc和面板停止有已知问题，不能依赖单个快捷键保证安全。

## 明确禁止

自动使能、未经确认的资格记录/工具参数、跳过碰撞/限位、放宽时效掩盖卡顿、旧观测续期、用假回读宣告成功、未知停止后继续作业。
禁止直接运行归档脚本、手删控制锁、结束不明进程、在真实数据目录跑会写数据的测试。
硬件验收记录使用[已有模板](real-hardware-acceptance.md)，新记录必须写适用版本/工具、时间、输入与实测、失败和未验证项，不能由Agent自动填通过。
