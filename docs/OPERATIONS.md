# 运维、数据与恢复

## 数据保护

先查实际进程的ELFIN_DATA_DIR/桌面userData数据位置，不读取或公开.env凭据。backend/data只是源码默认值，不是所有入口统一数据目录。
备份点位、场景、程序、工具/IO、设置及资格记录时分别标来源、版本和敏感性；不把现场资格导入另一台设备当有效。
实际备份/恢复需在任务允许、无活动写入且按现场规程停稳的窗口进行。本轮不复制或修改运行数据。

## 升级与迁移（计划门槛）

1. 明确基线、变更、旧数据格式和回退目标；保护当前未提交内容。
2. 备份后校验可读性/哈希，在新目录演练，不覆盖唯一原件。
3. 迁移先预览差异；稳定ID和引用保留，重名需人工可见消歧。
4. 失败不提交半份状态；回退应用前确认数据格式是否可向后读。
5. 验证冷启动、保存重开和完整任务；绝不恢复运行中程序或自动重放IO。
6. 真机参数改变使旧资格失效；应用文件回退不等于物理状态恢复。

## 故障处理

先区分用户输入/解析错误、状态过期、模型/相机失败、控制器拒绝、通信未知、已执行但结果未知。不要统一显示“重试”。
停止未知先处理现场保护和原会话证据，不通过强制刷新、关进程或重连“清状态”。记录任务ID、阶段、来源、时间、连接和版本。
诊断包默认脱敏；full参数当前有错误声明，不能据它判断已经导出完整值，也不能为修选项而取消脱敏。
保留失败日志，但做容量上限；事件、图像、模型下载与个人/设备标识分别设保留策略，不能无限写盘。

## 综合性能

基线需要3D+相机+CPU检测+程序+日志同时运行，统计帧龄/长任务/内存/控制调度。资源不足先降非关键画面，不降限位、碰撞、状态时效和停止保护。
指定设备稳定30fps需实测；预览/采集/检测帧率分开。短测不证明小时或天级稳定。

## 发布与恢复

开发5173、浏览器发布8710与桌面产物分离；当前dist为开发跳转，发布未达标。构建/发布另需授权，不在本轮执行。
产物应含源码/契约/模型指纹、依赖与许可、迁移、回退、已验/未验清单；检查配置、日志和打包内容不含凭据。
旧文档恢复见[归档规则](DOCS_GOVERNANCE.md)；归档不是运行数据备份，不能代替本节的恢复演练。
