# 项目上手文档

本页命令是说明，不是本轮已执行记录。先看[STATUS](STATUS.md)和[操作边界](ROBOT_OPERATIONS.md)。只读审查不需要启动项目。

## 1. 准备

在项目根目录使用PowerShell。Python声明为3.11及以上，实际兼容以pyproject与检查为准；Node/npm按锁文件及当前依赖要求准备，不随意升级。
读取package.json、web/package.json、backend/requirements.txt；相机是可选依赖，不为看文档安装SDK。

只检查现有环境的入口：

```powershell
powershell -NoProfile -File tools/env_doctor.ps1 -CheckOnly
node --version
npm.cmd --version
```

CheckOnly不修复环境；不要误用默认体检代替只读，它可能修复虚拟环境/安装依赖。

## 2. 离线开发启动（获得启动授权后）

保存过的自动连接偏好可能存在。只做离线演练时，启动前设置进程级禁真机，不要单凭“默认仿真”判断隔离。

```powershell
$env:HUYAN_NO_REAL = '1'
.\start.bat dev
```

然后访问http://127.0.0.1:5173。该命令可能准备依赖、启动后端热重载与Vite，不是无副作用检查；HUYAN_NO_REAL不禁止摄像头，仍不要主动开启设备。
不要在真机作业期间使用热重载。已有服务可能被复用，不能假定新环境变量改变了已有进程；先核对服务归属与模式，必要操作须另有授权。

统一热更新入口：`.\start.bat`。start/web/dev/restart均复用同一5173前端和8710后端，不再启动旧桌面包或独立预览副本。网页只使用 http://localhost:5173/。

## 3. 认识入口差异

| 入口 | 实际含义 |
| --- | --- |
| start.bat（无参数） | 统一5173热更新入口，复用唯一前端/后端 |
| start.bat web | 同一5173热更新入口，复用已有前后端 |
| start.bat dev | 同一5173热更新入口，复用已有前后端 |
| start.bat build | 可能安装依赖，强制前端构建 |
| start.bat restart | 同一热更新入口，复用健康服务，不额外打开桌面 |
| start.bat stop | 停止已核验的5173/8710开发服务；不是物理急停 |
| start.bat package | 生成发布产物，需独立授权与发布验收 |

当前生产构建已替换旧开发跳转，并生成web/dist/build-identity.json。最终打包和当前源码身份以STATUS的本轮证据为准，不能拿旧EXE冒充新构建。

当前预览只使用 http://localhost:5173/，不再启动隔离网页服务或冻结快照。单元与后端隔离测试继续使用正式临时数据运行器，不读取工作站数据。

视觉检测需要独立`.venv-vision`及`backend/requirements-vision-lock.txt`；桌面构建还需`requirements-vision-build.txt`。远程配对和单向WebRTC已实现并通过本机合成视频互通；手机可信HTTPS、权限和跨机网络未验，不要绕过浏览器权限或自动开放外网。

## 4. 第一次体验

先确认页面仿真/无真实链路，再在场景添加普通物体→点位预览→明确执行仿真目标。功能页可体验现有井字棋/分拣；完整条件见[用户指南](USER_GUIDE.md)。
连接、断开与模式切换只在“驱动与许可”页主动操作；设置页“前往驱动”只导航。工程页→显示可保存下次启动的完整/轻量模型，不刷新当前页面或中断任务。

AI明确动作先走本地规则，逐条标明来源；已配置模型不等于健康。模型解释须本轮明确允许发送当前要求和最近6条对话，默认关闭且发送后复位，不自动附带现场数据。待补充要求可选本条补充，120秒内生成新的待确认计划，补充不续期；取消、过期或现场变化后重新提出，历史不继承执行许可。

视觉页远程相机区可选择“工件颜色与轮廓”再配对，远程设备须可信HTTPS和主动授权。结果可查看、标定及只读找物/计数，不能驱动取放；接收时间/时钟估计不代表真实采集时间。重新配对会清除旧来源和标定，真实手机与跨机部署仍需现场验证。

场景支持受控静态GLB：先检查单位、尺寸、来源和许可，再确认导入；不支持任意格式或外部资源。CPU YOLO等候选不属于当前已交付能力。

功能页另有“视觉找物”“计数检查”“配套装盒”“图案拼摆”：

- 找物/计数先在视觉页手动采集，按名称/颜色/形状与检查区域筛选，点一次“查找目标”或“检查托盘”。只读检查不运动；计数可填预期数量，错位检查填已标定格位 `X,Y`（毫米）与容差。只支持有限颜色/轮廓，不能当通用工业检测。
- 装盒填写每格颜色；拼摆可点“填入图案”。随后“按配方布置物料”并通过系统确认→手动采集A区并核对标定→新鲜识别→预览格位→预检完整路径→勾选人工确认→执行取放。A图案的10红料自动使用38毫米小工件。未知、缺料、容量不足或不可达不执行，不保证全部场景可达。
- 取消保留实际位置与已确认数量；若仍持件，确认停止后通过末端工具页正式停止吸气/释放，再整理或重新布料。完整条件见[用户指南](USER_GUIDE.md)。

状态栏可核对控制方、阶段与已确认步数；启动条件可定位对应处理页。系统→遥测→性能可显式采集同场景前后样本并导出，每秒采样、最多保留120条，离页停止；未测项不会填成正常值。系统→关于→更新/验证显示版本证据，没有当前匹配清单时明确提示缺失，历史结果不授予当前设备资格。以上入口存在不等于最终同版验收已通过，仍以STATUS为准。

## 6. 本地桌面构建与恢复

```powershell
backend/.venv/Scripts/python.exe tools/build_desktop.py
```

该入口生成`output/desktop-release/win-unpacked/JiuShuRobotStudio.exe`，绑定独立源码快照并包含生产页面与独立视觉进程；无需开发服务器，不生成或发布安装包。构建需要现有依赖和写权限；当前快照指纹见`output/renewal/desktop-build-source.json`。

在设置→配置档案→数据备份与恢复导出备份。恢复先显示差异，仅创建独立副本；桌面确认切换会先关闭自己的后端，再重启到该副本。运行中任务、凭据和硬件资格不会恢复。合法保存后可正常重开。需要返回上次数据选择时，先正常关闭桌面并另存用户数据目录中的两个选择文件，再将`data-selection.previous.json`复制为`data-selection.json`后启动；该指针不覆盖业务数据。不要手工覆盖原数据或删除恢复副本；共享后端不允许由此强制关闭。

版本恢复点是`simulation-stable-2026-10-30`，仅为仿真基线。当前有大量未提交实施和用户修改，恢复前另存整个工作区及所需数据；不要直接reset覆盖。重建旧版本应在独立目录中检出并使用独立数据目录。

工艺录制页面已退役，旧 `#/studio` 收藏会打开程序编辑器；不会删除既有录制数据。新增绘制工作包当前终态见STATUS，未验证前不视为可用承诺。
