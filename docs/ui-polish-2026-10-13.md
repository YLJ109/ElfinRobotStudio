# 操作界面整理与验证

- 导航底部收起/展开工作面板；保持代码与未保存的名称；拖动宽度时取消尺寸过渡动画。
- 程序头部选择中文/EN补全；命令和工具动作支持英文前缀、中文前缀及拼音首字母。
- CodeMirror 编辑器提供行号、高亮、光标附近候选列表、键盘选择、撤销与滚动；按需加载。
- 程序库按钮分行排列，删除按当前选择的文件执行。
- 修改代码或任务参数使旧解析结果失效；中文和小写循环统一规范化后解析。
- 固定操作说明集中迁移到关于，保留错误、字段单位及松闸坠落风险的一句提示。
- 移除重复速度滑条、运动学驱动徽标、固定冲突说明卡和无折叠功能标题的箭头。
