工业外观中的孔洞、脚架和滚筒间隙不是精确网格碰撞；现有保守代理可能提前给出包络重叠。属性里保留说明和碰撞开关，不能把“包络重叠”描述成已证明的实体压碰。

## 跟随为何反复停住

沿截图配置检查了局部逆解、异步结果交付、输入采样、失败缓存及连续步进：

- 腕部接近对齐时，四次缩步仍可能大于同一关节分支允许的局部移动；失败目标又被长期记住。现在允许有界的进一步细分，不扩大关节信任域或 FK 接受容差。
- 小幅输入抖动使浮点目标每次不同，失败缓存不命中、失败原因也难以交付；新样本还会把原因改写成正常跟随。现在调度缓存只在相同方向、相同已接受关节的短期微小邻域复用，原目标和几何容差不量化。
- 反向输入不能继续使用旧方向的后台目标；新目标明确反向时撤销尚未执行的旧步，保留真实已接受位置。
- 慢求解超过结果交付时限可能反复重算。现在单轮350 ms、同局部请求累计700 ms协作预算，有界限频后重试，反向或离开邻域可重新求解。
- 合并全量回归又发现，临界腕姿仍会耗尽粗步预算；固定细分次数不足以覆盖更靠近对齐的姿态。补充 Jacobian 首步预测及经 FK 验证的连续零空间种子；远目标的微步收紧位置容差，并要求实际 FK 距离减少，避免原地不动也被当成微步成功。保持终点原有精度，不把真正的同 TCP 零空间调整误判为无用运动。

这不是把“数值未收敛”变成“几何不可达”，更不是关闭碰撞让机器人穿过去。界面区分局部求解受限、路径保护和输入丢失；原始原因收在求解详情中。测试覆盖左侧及270°、Y600/Z650截图范围、持续微抖、反向、奇异点穿越、固定朝向及原速度/关节/路径保护。

首次全量报告 `output/checks/huayan-fix-checks-861mefoy.json` 保留59组中1组失败的原始证据，未改低断言。失败腕姿及原30mm目标、可复现预算压力回归中，剩余误差由29.413mm降至0.034mm；精确J5=0、反向和零进展假收敛均新增检查。修正后的三个独立腕轴检查副本为 `uyzm6kea`、`6yosuqv2`、`nksg0dxy`，最终全项目结果以任务状态记录为准。

相机中的虚线骨架是旧观测的显示保持，不等于新检测。超过300 ms的旧采集观测不用于运动；空检测也算完成了一帧推理，因此检测 fps 不等于有效掌心更新率。已明确文案并展示解码、推理、往返及观测年龄；没有凭一张截图承诺真实识别率或降低有效期门槛。

## AI 的解析和执行规则

结果分 `chat / clarify / plan`。模型负责普通解释，明确支持的动作由本地规则解析并经白名单验证，再确定性生成代码、用真实项目解析器复查。模型文本本身不能发布任意 Python 或执行许可。

- “你好”、语法询问、否定、假设及引用历史不发布运动计划；新对话、丢弃、断线、故障和现场变化会撤销旧提案。
- 明确的速度、点位、关节角、等待、原始 DO 电平和工具语义动作可转换；速度保持要求中的次序，仅明确的末尾全局速度修饰可以前移。
- 点位按稳定编号/名称解析。工具动作必须匹配当前工具能力；真机还须有已确认的工具与有效 IO 映射，不能把 DO1 自动解释成吸附。
- 缺取料点、接近/撤离路径、工具或返回点时追问，不发布半份计划。“回起点”不能擅自翻译为六轴零位。
- 整份计划的路径采样预检通过后才启动，避免先改变 IO 再发现后续路径有风险。跟随、暂停调试或停止确认占用时拒绝 AI 抢占。
- 提案绑定消息、会话、工具、起点、场景、期限和一次性令牌；旧消息、改写代码、重复点击不会复用执行许可。编辑器中的改写需走程序自身检查。

例如在已保存对应点位、工具能力明确的条件下，可说：

> 速度8%，经接近点P2到P1吸取物体，经撤离点P2和接近点P4到P3释放物体，经撤离点P4返回P1。

这里只编排已定义的点位与工具动作。仿真工具动作目前仅改变虚拟状态，不代表工件会自动附着、真实抓牢或已经完成搬运。暂未实现任意复杂工艺自动规划、物料附着物理或真正流式回答。

## 程序语法

推荐受限 Python 风格；已存在 P1 时，例如：

```python
# 准备明确速度，再运动到已有点位。
SPEED(10)
for i in range(2):
    MOVEJ("P1")
    WAIT(0.2)
```

兼容旧式逐行 DSL，但同一文件不能混用两种控制流格式：

```text
# 旧式语法，P1 必须存在。
SPEED 10
LOOP 2
MOVEJ P1
WAIT 0.2
END
```

中文别名、变量/列表/字典、条件和固定参数函数详见程序内语法页。禁止 import、文件/网络访问和任意 eval/exec。`DOUT 0,1` 对应 DO1，不是 DO2；原始电平不承诺工具物理效果。MOVEL 当前只开放仿真。
