# 02 前端 UI/UX 与主题规范

## 1. 视觉定位

采用清晰、克制、可长时间使用的工业工作台。信息层级、读数、状态和动作优先；3D 用于空间理解，不让装饰效果遮挡操作。深色、浅色、增强对比三套主题共用语义 tokens。

本轮使用 UI/UX Pro Max 检索。自动设计系统结果包含营销首页 Hero/CTA 和远程字体，未用于工作台。更窄的产品检索命中实时监控与事件管理，可借鉴数据密度和状态语义；没有精确机器人 HMI 模板，工业布局由本方案给出。Vue 表单检索命中通用验证与 modifiers，但工业数字输入不能在中间字符阶段直接强制数值转换。

## 2. 主题 tokens

| token | 深色候选 | 浅色候选 | 使用 |
|---|---|---|---|
| canvas | `#10151D` | `#F3F5F7` | 应用背景 |
| surface | `#18212C` | `#FFFFFF` | 面板 |
| surface-raised | `#202D3B` | `#E9EEF3` | 悬浮与选中区域 |
| text-primary | `#F1F5F9` | `#17212B` | 标题和关键读数 |
| text-secondary | `#BAC6D4` | `#455468` | 标签和说明 |
| border | `#536477` | `#75859A` | 控件边界，逐组合测对比度 |
| action | `#58D3EF` | `#086E87` | 主操作与选中 |
| on-action | `#08232D` | `#FFFFFF` | 主按钮文字 |
| success | `#61D7AF` | `#176A49` | 到位和成功 |
| warning | `#F4C66B` | `#805A06` | 可解释警告 |
| danger | `#FF97A3` | `#AD1734` | 危险与停止 |
| preview | `#6BE5F3` | `#086E87` | 目标/残影 |
| actual | `#D3DCE6` | `#334155` | 实际位置 |

以上是候选色，不等同已测合规。正文对比度目标 ≥4.5:1，关键大字和控件边界按适用标准单独测量。状态同时提供文字、图标或线型，颜色不作为唯一编码。

分层：primitive → semantic → component。组件禁止散落硬编码色值；图表、3D、SVG 和 CSS 从同一主题读取语义。切角可以作为轻微品牌元素，但输入框有效宽度、焦点框和点击区必须完整，不再用 clip-path 裁掉输入内容。

字体本地优先：中文系统无衬线，数字 Cascadia Mono/Consolas + `tabular-nums`；如需内嵌字体，先核验许可。常规正文 14–16 px，辅助最小 12 px，主读数 16–20 px；紧凑密度只缩间距，不把重要文字压小。

间距基于 4/8/12/16/24 px；卡片默认内边距 8–12 px，避免叠加两层相同 padding。桌面控件高 32–36 px；触屏模式高 ≥44 px、相邻点击区足够分隔。弹层、通知、菜单、对话框使用明确 z-index 层级。

## 3. 应用布局

```text
┌ 系统/工程/设备/工具身份 ─── 运行状态 ─── 主动作/软件停止 ┐
├ 导航 ┬ 工作区/可调面板 ┬ 三维或程序画布 ┬ 按需属性/诊断 ┤
│      │                │               │                │
├──────┴────────────────┴───────────────┴────────────────┤
│ 数据来源、质量、坐标、速度、当前步骤、连接与诊断入口       │
└────────────────────────────────────────────────────────┘
```

- 1920×1080：左侧建议 360–440 px、右侧按需 300–360 px，中间充分展示工位。
- 1366×768：左侧约 320–380 px，右侧变抽屉，日志折叠；底部动作区保持可见。
- 1024×768：单侧面板 + 画布切换；不把多列全部挤成细条。
- 768 以下：只读监控/工程浏览可适配，完整真机操作仅在完成专门触屏验收后开放。
- 浏览器 125%、150%、200% 缩放都要检查；窄窗口支持自然换行与单一滚动容器。
- Grid 的可伸缩区域用 `minmax(0, 1fr)`；可滚动 flex 子项明确 `min-height:0/min-width:0`。
- 标题、动作区 `flex-shrink:0`；日志/消息区滚动。不得用全局 `overflow:hidden` 隐藏内容缺陷。
- 面板宽度、折叠、主题、密度、视角是用户偏好；控制状态、实际工具和就绪状态不能恢复为本地旧缓存。
- 布局支持“示教 / 编程 / 调试 / 监控”四套预设，允许一键恢复默认。

## 4. 状态表达

| 场景 | 显示 | 动作 |
|---|---|---|
| 尚未收到数据 | `--`、等待状态 | 显示可用的连接操作 |
| 仿真 | 全局仿真徽标、仿真工具/IO来源 | 仿真动作可独立执行 |
| 真机正常 | 控制器身份、数据年龄、当前工具 | 按后端联锁开放动作 |
| 数据过期 | 最后已知 + 过期时长 | 禁止依赖当前姿态的执行 |
| 预览 | 请求目标、已求解目标、残影 | 预检后执行 |
| 运动中 | 实际值、目标、阶段和进度 | 停止保持可达 |
| 拒绝 | 原因、字段/步骤、恢复入口 | 不伪装已完成 |
| 结果未知 | 指令已发送但无法确认 | 核对实际状态后恢复 |

主按钮继续由后端合法动作推导。前端不得用本地布尔值判断“允许运动”。禁止默认显示未连接为零位、绿色正常、已使能。

软件停止明确标注为软件停止请求，物理急停状态另显示。页面按钮不会获得物理急停的安全等级。

## 5. 统一数字输入模型

当前“值改不了”的根治方案是区分 `actual / committed / draft / pending`，不让状态帧覆盖正在编辑的草稿。

| 状态 | 规则 |
|---|---|
| 浏览 | 展示后端已确认值、单位和版本 |
| focus/editing | 保存编辑开始的 revision，草稿为字符串 |
| 中间字符 | `-`、`1.`、空字符允许暂存，不立即报 API |
| Enter/保存 | 完整解析、有限数、单位、范围、精度检查 |
| 提交中 | 显示 pending，防重复提交，保留草稿 |
| 成功 | 使用服务端确认值与新 revision，清除 dirty |
| 失败 | 保留用户输入，字段旁显示原因 |
| 外部更新冲突 | 展示当前值与草稿，选择重载或重新提交 |
| Esc | 撤销草稿；事件先服务于输入编辑 |
| blur | 低风险属性可提交；影响运动/负载/工具的修改走明确保存 |

禁止：每个键击写网络、watch 全部 snap 重填输入、NaN 转 0、用 CSS 禁用代替业务只读、输入失焦后无提示丢弃修改。

共用组件：`NumericField`、`ReadoutField`、`UnitField`、`SliderReadout`、`VectorField`、`DirtyForm`、`RevisionConflict`。边界校验由领域契约驱动；整数位号、浮点坐标、角度、小数步长使用不同类型。

物体属性：选择对象后创建草稿，X/Y/Z/尺寸/半径可输入；修改实时预览独立于保存；重力移动只刷新“实际位置”，不覆盖编辑中的目标。保存检查正尺寸、有限数、允许坐标，撤销回到已确认值。

## 6. 示教工作台

- 关节页：六轴实际读数、目标滑块、±点动、单位、软限位、速度、工具状态。
- 目标角读数按用户要求只读；修改通过滑块、±、点位载入。未来数值精确编辑可作为明确打开的独立模式，不能悄悄恢复可输入框。
- 笛卡尔页：明确基座/工具/工件坐标、当前位置与目标、平移步长 mm、旋转步长 °；不让平移仍显示“1°”。
- 拖动只改变残影和求解目标；实际机器人保持原位。实时点动属于独立模式，必须显式进入并按住操作。
- 滑块至少有键盘/±替代，鼠标离开或指针取消时结束实时点动。
- 求解状态：计算中 / 有效 / 部分可达 / 不可达 / 数据过期。错误就近显示，不把每次滑动失败写满执行日志。
- 全部六个关节目标由 IK 同步刷新；TCP 展示由同一组 q 的 FK 刷新。基座 X 变动时 Y/Z/姿态可受约束保持；工具坐标运动可能联动基座多项读数。
- `requested` 与 `achieved` 分开。部分可达时显示退回比例、达成位置和差值；执行按钮绑定达成目标，需明确确认退回目标。
- 残影与实际模型有明确样式区别，目标 TCP 标记与路径图例一致。
- 目标差为零时显示“已在目标”，不再让用户误以为程序没运行。

## 7. 点位与工位

点位卡片的 q/TCP 默认只读，支持复制数值；编辑名称/标签、重新示教和删除在明确动作中完成。点位来源分为真机示教、仿真、导入；显示机器人/工具/坐标 revision，依赖失配需重新验证。

工作空间提供对象拾取、平移/旋转 gizmo、网格吸附、数值属性、工具安装预览、坐标轴显示、干涉标记、图层与隐藏。隐藏对象只影响显示，不能默默退出碰撞计算；碰撞参与是单独配置。

## 8. 程序与工艺编排

- 文本编辑器：语法、行号、字段补全、单位提示、点位/工具/IO 引用、错误定位。
- 节点编排：源自同一 IR；不另造运行引擎。无法表示的高级文本语句明确提示不可图形编辑。
- 工具动作提供 `夹紧/松开/吸附/释放/等待抓取成功` 语义，显示实际 IO 映射。
- 运行面板区分编译通过、预检通过、提交、执行、等待 IO、暂停、到位、失败、未知。
- 显示冻结程序版本；用户改编辑区不改变运行版本。单步执行、断点、仿真倍速和恢复点有清晰语义。
- 运行中工具切换被拒绝，提示停止后进入换装流程。
- 保存/导入/导出、版本比较、依赖列表、节拍分析独立可见。

## 9. AI 页面

按用户要求，将模型名、清空、状态与“说要机器人做什么”合并在同一个标题区，不保留上下两条被压缩的窄盒子。

布局：标题 `auto` → 消息/计划区 `minmax(0,1fr)` → 输入区 `auto`。标题和输入不收缩，消息区唯一滚动；模型徽标可换行，清空按钮保持完整点击区。AI 输入至少两行，能扩展但有上限；中文输入法 composing 时 Enter 不发送。

计划显示每步动作、工具、坐标、IO、可行性、依赖、预检结果和确认项。“生成计划”与“执行已验证计划”分开；危险/未知能力不得直接生成可执行按钮。清空历史不取消当前执行，两者有不同入口。

AI 分为工艺建议、资料解释、任务草案、故障解读；引用厂家资料或项目证据，无法确认时显示未知。禁止把推测错误原因做成确定诊断。

## 10. 工具页面

工具库卡片：无工具/通用夹爪/吸盘/自定义工具，预览缩略图、TCP、质量、几何 revision、接口类型与验证等级。

顶部常驻实际安装状态：已识别、人工确认、仅控制器配置、身份冲突、未知。读不到硬件身份显示“未能识别，可手动选择”，不循环重试刷日志。

手动选择只更新候选工具；点击“确认实际已安装”后经过停稳、参数和能力检查更新安装档案。确认对话框仅用于真实工具更换及高影响参数，不为每个普通属性添加阻碍。

夹爪显示开口、夹紧/到位/物体检测；吸盘显示真空状态、吸附/释放/泄漏报警。不存在的传感器显示不可用，不能模拟成真实到位。

## 11. 遥测、诊断、设置与日志

- 遥测按机器人、通信、工具、工艺分组；每项显示来源、单位、新鲜度、是否实测。
- 图表保留峰值、显示缺口；低频曲线不能当作高频振动分析。
- 日志按 exec/request/step/command ID 过滤，支持汇总和精确原始视图。
- 同一连不上原因只记一次状态变化，加重试计数；不每秒重复一段长日志。
- 设置区分用户偏好、工程参数、设备连接、工具配置和安全参数；影响执行的改动提示需重新预检。
- 明确两个现有入口：Web 工作台和 PyQt 协议诊断面板；产品安装后主入口只有工作台，诊断面板保留为工程工具。

## 12. 可访问性与交互质量

键盘遍历顺序与视觉顺序一致；焦点明显且不被 sticky 区域遮挡；错误有 `aria-describedby`，状态消息节流播报。表单输入、编辑器、模态框聚焦时全局导航快捷键不得抢输入。

Esc 在编辑时先取消草稿；应用提供独立、文档化的软件停止快捷键，并验证编辑器焦点下仍可调用。保留现有快捷键兼容需要明确映射，不能在输入框里既声明 Esc 急停又直接 early return。

UI 状态改变可用 100–180 ms 微反馈；告警和数据立即反映。尊重 reduced-motion；它影响装饰动画，不隐去机器人实际运动信息。

## 13. UI 验收矩阵

| 用例 | 必需证据 |
|---|---|
| AI 标题合并 | 1366/1920、125/150% 下没有独立旧工具条和文本裁切 |
| 输入编辑 | 连续状态帧下输入负数/小数/中间字符、失败重试均不丢草稿 |
| 点位与目标角 | 真正只读、可复制、不出现意外数值滚轮修改 |
| 笛卡尔残影 | 快速拖动最新值胜出，actual 不动，q/TCP 一致 |
| 工具状态 | 自动识别/人工确认/冲突/未知各有不同标签和动作 |
| 低分辨率 | 动作区可见、单滚动、无根级横向溢出 |
| 主题 | 所有状态页与 3D 一致，自动测文本/边界对比 |
| 键盘与触屏 | 焦点、替代操作、pointercancel、缩放均通过 |
| 浏览器故障 | WebGL 丢失、WS断线、API失败均有可恢复提示 |

参考：[Vue 性能指南](https://vuejs.org/guide/best-practices/performance)、[Vue 表单](https://vuejs.org/guide/essentials/forms.html)。
