# 04 J6 法兰末端工具、识别与切换规范

## 1. 用户需求与范围

支持夹爪、吸盘（用户所述“洗盘”按吸盘理解）、多个可切换工具、自定义末端模型。读取可识别的实际安装工具；读不到时，用户可以手动选择并确认。

工具安装在 J6 后的末端法兰坐标，不修改 J6 本身的轴定义、URDF 长度或关节限位。末端工具几何、TCP、负载、碰撞形状和 IO 行为作为独立资产进入系统。

先提供几何模板：无工具、两指夹爪、单吸盘、吸盘阵列、自定义刚性工具、快速换枪装置 + 子工具。模板不是已安装硬件证据，也不预设用户实际品牌、开口、吸力、接线和质量。

## 2. 工具档案

| 分组 | 字段 | 验证 |
|---|---|---|
| 身份 | id/name/vendor/model/serial/revision/type | 缺硬件身份允许手工档案，标明来源 |
| 安装 | 法兰标准、安装变换、快换接口、锁紧信号 | 机械尺寸依据图纸/实测 |
| 几何 | glb/源模型/hash、单位、碰撞模型 | mm/m 转换，安装对齐、许可 |
| TCP | 名称、`T_flange_tcp`、标定样本/质量/版本 | 平移与方向分别验证 |
| 负载 | mass_kg、com_mm、inertia、有效负载范围 | 缺数据标未知，禁止猜成 0 |
| 电气 | DO/DI/AI/AO、极性、默认态、接口地址 | 真实探测与电气图对应 |
| 动作 | open/close/grip/release/activate、超时 | 动作前置、反馈、失败与恢复 |
| 识别 | read-only identity query、信号规则、置信级 | 必须能区分多个工具才自动匹配 |
| 仿真 | 开合关节、吸附范围、抓取约束、释放 | 明确简化物理与传感器语义 |
| 证据 | 文档、测试、时间、操作者、硬件条件 | 未验证不能显示为已验证 |

允许一个工具多个 TCP：抓取中心、指尖、吸盘中心、加工点。选用 TCP 必须更新计划依赖；工具存在性与 TCP 选择不合并为一个布尔值。

示例为拟议工程格式：

```json
{
  "schema_version": 1,
  "id": "gripper-template-01",
  "revision": "r1",
  "type": "parallel_gripper",
  "identity": {"source": "manual", "hardware_id": null},
  "geometry": {"asset": "tools/gripper.glb", "unit": "m"},
  "mount": {"parent_frame": "flange", "translation_mm": [0, 0, 0], "quaternion_xyzw": [0, 0, 0, 1]},
  "tcp": {"status": "unvalidated", "translation_mm": [0, 0, 100], "quaternion_xyzw": [0, 0, 0, 1]},
  "payload": {"mass_kg": null, "com_mm": null, "status": "unknown"},
  "actions": {},
  "io_mapping": {}
}
```

示例 100 mm 只说明格式，不作为真实工具长度默认值；null 不传给要求数值的厂家命令。真实启用条件由硬件工艺决定。

## 3. 自动读取与识别策略

优先级按证据质量排序：

1. 支持身份查询的智能夹爪/工具控制器：只读设备 ID、型号、序列号、固件，精确匹配档案。
2. 带工具 ID 的快换系统：读 ID + 锁紧反馈，与已标定映射核对。
3. 已接线的编码 DI/RFID/PLC 工具号：读取已验证的编码表；过期/冲突不匹配。
4. 控制器当前 TCP/工具名称/负载：只作为“控制器配置”证据，不证明实物安装。
5. 无硬件识别接口：人工选择并确认；禁止假装自动识别。

普通气动夹爪和吸盘经常只有开关 IO，没有身份信息。单个 DO 状态或真空信号无法证明是哪一个工具。视觉识别工具只有经过现场标注验证才能成为辅助证据，不能替代锁紧与机械安装确认。

读取使用 CapabilityRegistry 中明示的只读能力；自动检测不发送开合、吸附、松闸、切换 TCP 或写负载命令。不通过盲扫网络、SSH 读目录或试写 IO 识别工具。

连接后检测一次，工具相关身份信号发生变化时重读；有限次数退避，不能一直刷“未识别”。保留最近人工选择作为候选，不在重连后假定实际工具未变。

## 4. 安装状态

| 状态 | 含义 | UI/执行 |
|---|---|---|
| none_confirmed | 用户确认无工具或有效身份指示无工具 | 法兰示教；工具动作不可用 |
| detected_verified | 硬件身份/锁紧与档案匹配 | 允许经过其他联锁的工具动作 |
| manual_confirmed | 无可靠身份，用户确认已装该工具 | 展示人工确认来源与时间，依赖重新预检 |
| controller_config_only | 只读到控制器工具/TCP 名 | 需要确认实际安装；不称自动识别成功 |
| unknown | 无证据或断线后不能确认 | 可查看/选择档案，不允许未知工具动作 |
| conflict | 检测 ID、人工选择、TCP 或锁紧不一致 | 禁用依赖工具的执行，显示具体冲突 |
| changing | 工具切换流程中 | 作业锁定，停止仍可用 |
| fault | 锁紧、气压、反馈、驱动故障 | 停止相关动作，按工艺恢复 |

无工具模式也要明确确认，不能“读不到 → 视为无工具”。机器人工作包络计算必须包含实际工具；不允许为了运行而忽略未知几何。

## 5. 手动切换事务

1. 进入换装界面；检查执行器、程序、Jog、自由拖动均无活动，实际状态新鲜且停稳。
2. 选择候选工具；展示匹配机器人、安装示意、TCP/负载与接线。
3. 用户完成实际机械换装，确认夹持/锁紧与管线；如有快换硬件，读取锁紧反馈。
4. 读取硬件身份并核对；无识别能力允许人工确认，不伪造检测结果。
5. 校验 TCP、负载、IO 档案；若当前需要写控制器参数，先有协议能力、前置条件与回读契约。
6. 更新工具配置时记录各步前值、回执和回读，禁止把多条厂家写命令视为天然原子事务。
7. 全部必要回读一致后激活新 mounted revision，重建场景与碰撞体，清除残影/旧计划。
8. 所有依赖旧工具的程序/点位标注需重验证；不可静默转换成新 TCP。
9. 如某步失败：保留切换未完成与已确认的实际结果。无法确认配置恢复时锁定相关运动，不谎称已回滚。

工具切换不触发机器人自动移动。若有专用自动换枪工位，单独建立经过预检的换枪工艺、停稳/互锁、锁紧传感器和恢复步骤。

## 6. 坐标与几何

```text
T_base_tcp = T_base_flange(q) × T_flange_mount × T_mount_tcp
T_base_gripper_finger = T_base_flange(q) × T_flange_mount × T_mount_finger(opening)
```

统一约定避免把安装变换重复计入 TCP：如果档案提供 `T_flange_tcp`，执行计算直接使用这一项，不能再乘同一安装偏置。数据 schema 明确使用哪种表示。

- 夹爪手指随开合变化；其碰撞模型不仅是 TCP 一个点。
- 吸盘包含杯体、支架和管线保守包络；吸附工件后工件成为随动碰撞体。
- 快换工具包含母盘/子盘/锁紧外形，工具长度与惯量包含安装件。
- 工具读数与残影使用同一 TCP；法兰、工具安装轴和多个 TCP 可切换显示。
- 实际工具传感器缺失时，动画只能表达命令/模拟状态，标注“未测量开口/吸附”。

## 7. 夹爪动作契约

`Grip` 至少包含：目标开口或开关动作、速度/力限制（硬件支持时）、完成条件、物体检测条件、timeout、失败后策略。

完成不能只根据 DO=1 判定。可能的结果：关闭到位、物体检测成功、关闭但未抓到、行程卡住、反馈缺失、驱动错误、执行未知。

双输出气动夹爪：开/关信号互斥、电气极性明确、防止两个线圈同时输出；是否脉冲/保持按真实阀门档案。默认失效态按工艺风险定义，不能一律断电松开导致掉件。

智能夹爪：寄存器/协议适配，支持开口/力/状态读回时才显示真实数值；伪造“夹持力百分比”不可接受。

## 8. 吸盘动作契约

`VacuumOn` → 等待真空阈值/数字到位 → 持续确认 → 搬运；`VacuumOff` 与可选吹气释放各有互斥和超时规则。

参数：真空反馈类型、极性、阈值/迟滞、建立时间、泄漏判据、保持气源策略、释放脉冲时间、工件类型与允许加速度。

无真空传感器时允许配置为“命令已发送，抓取未证实”；是否允许后续搬运必须在工艺风险评审中定义，不能自动当作抓取成功。掉件/气压下降的恢复策略与停止策略由负载风险决定。

## 9. 程序工具语义

新增 IR 节点而非硬编码某 DO：`RequireTool`、`SelectTCP`、`Grip`、`Release`、`VacuumOn`、`VacuumOff`、`WaitToolState`、`AttachPayload`、`DetachPayload`。

源码语法版本化。示例为拟议 v2，不是当前 DSL 可执行语法：

```text
REQUIRE_TOOL suction-cup-A
USE_TCP pickup-center
MOVEJ approach
MOVEL pickup SPEED_MM_S 40
VACUUM ON
WAIT_TOOL vacuum_ok TIMEOUT 2.0
ATTACH_PAYLOAD part-A
MOVEL retreat SPEED_MM_S 40
MOVEJ place-approach
MOVEL place SPEED_MM_S 40
VACUUM OFF
WAIT_TOOL released TIMEOUT 1.0
DETACH_PAYLOAD part-A
```

程序编译冻结工具、TCP、负载、IO revision；工具改变需重新编译/预检。现场程序执行中禁止自由切换，只允许程序明确声明并具备硬件换装能力的流程。

## 10. 工具仿真

夹爪：开口范围、开合时间、物体检测近似、抓取约束、释放、碰撞。吸盘：吸附接触与距离条件、法向角容差、工件可吸附标签、建立延迟、泄漏/失压注入。

抓取后添加约束，不只把物体瞬移至 TCP。物体重心、工具与工件总负载更新；释放恢复重力。简化模型不能宣称真实吸力、摩擦或漏气预测。

自动识别也可仿真：hardware_id、无设备、错工具、锁紧未到位、反馈延迟。全部显式带仿真标记，不能写入真实 mounted 状态。

## 11. 现场需要资料

每个真实工具：名称/型号、机械图或 CAD、实际安装照片/测量、TCP 定义、质量/重心、输入输出与电压、驱动协议、反馈传感器、失效行为。能拿到哪项就用哪项，不要求为纯几何预览补齐全部硬件资料。

已有安装工具先读取可用身份和控制器配置，再人工补档案。缺身份接口不是阻断整个工具系统的理由，人工确认路径是正式功能。

## 12. 验收

- q 任意变化时工具刚体准确跟随末端法兰；换装不会改变机器人本体 FK。
- 工具 TCP 改变后 IK/目标读数/残影/预检一致，旧计划全部失效。
- 空工具、夹爪、吸盘、快换组合可保存、导出、导入并显示 revision。
- 真实识别不调用任何写命令；读不到时可手动选择，不刷屏、不推断无工具。
- 身份冲突、锁紧失败、切换期间断线、参数回读不符有确定锁定/恢复行为。
- DO 命令回执不能被误报为夹持/吸附成功。
- 抓取工件后预检包含随动物体、质量与包络，释放后恢复场景物理。
- 仿真与真机工具档案/安装状态/动作日志互不污染。
