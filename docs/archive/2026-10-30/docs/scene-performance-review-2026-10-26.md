# Scene 高频路径优化与离线复核

范围：仅修改 `sim/web/src/scene.js`，新增 `sim/web/scripts/check-scene-performance.mjs` 和本报告。未修改App/store/HandPanel、后端、掌心输入、工具或皮肤实现文件。未操作浏览器、摄像头、真机、服务，未打包或重启。

## 已定位的重复工作

使用实际scene函数和真实Three.js数学/几何对象，在Node离线运行；模拟DOM、模型加载响应和WebGLRenderer。模型网格使用小型盒子替身，保留实际URDF层级、关节变换及真实吸盘工具构建/皮肤方法。计数包围 `updateMatrixWorld`、`updateWorldMatrix`、Vector3/Quaternion显式构造、几何dispose、BufferAttribute上传标记和render调用。

每批600个重复快照，按30Hz时间戳送入关节、残影、跟随框、8个胶囊体和一个对象；另测180次rAF回调与100次相同路径设置。

| 离线调用场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 600相同快照：额外节点矩阵更新 | 63,600 | 0 |
| 同批：场景显式Vector3构造 | 30,600 | 0 |
| 同批：场景显式Quaternion构造 | 600 | 0 |
| 100次相同路径：几何dispose/替换 | 100 | 0 |
| 180个静止rAF回调：向量/四元数构造 | 180 / 90 | 0 / 0 |
| 同批静止回调：BufferAttribute上传标记 | 91 | 2（初次同步） |
| 同批实际执行render调用 | 90 | 90 |

这些是特定离线用例中的调用计数，不是全部JS堆分配、GPU执行时间或现场FPS。正常render的矩阵更新仍在：同一静止样本前后均有11,880次节点更新，没有靠冻结实时场景把这个工作隐藏掉。单次CPU微基准受JIT/GC影响，重复快照耗时前33.36ms、后一次25.38ms，其他运行有波动，空闲段也未证明更快；不据此宣称整页提速比例或稳定帧率。

## 改动

- 不变残影角度不再重算整棵树；颜色、报警闪烁、透明度仍独立更新。关节变换从“归零再旋转”合为等价的单次轴角设置，不改变URDF原点层。
- 去掉每次跟随快照对整个display subtree的强制矩阵更新；TCP每渲染仍更新所需祖先链，使用复用向量/矩阵完成坐标转换，不丢弃新姿态或TCP偏移。
- 胶囊体使用复用端点/方向向量，保留每次位置、半径、长度和方向更新。
- 跟随框逆旋转四元数复用；跟随线仅在端点变化时标记上传。旧目标仍按后端状态变化，不在scene增加检测有效期或复用逻辑。
- 轨迹插值输出和轨迹落点复用缓冲；计划路径使用DynamicDrawUsage和可增长缓冲，不因相同坐标的新数组引用而重建。扩容时仍释放旧几何；缩短路径时更新drawRange和有效范围包围球。
- 修复已有对象碰撞/选中色：不再每快照清掉碰撞状态；解除碰撞恢复实际sel颜色，而不是读取未设置的hit。安全红色优先于选择青色。
- 静止30Hz绘制门限增加0.5ms浮点容差，避免精确60Hz回调被33.333ms边界误跳。控制采样频率、后端运动状态和输入队列未改变。
- 沿用原DPR与画质策略，没有新增降低分辨率的行为，没有写入用户视角/模型质量存储。

## 主代理浏览器核对入口

继续使用 `window.__elfinScene.dprInfo()`，旧字段保持兼容：

- `averageRenderMs`：原有整帧CPU耗时统计，含场景更新及提交。
- 新 `averageSceneUpdateMs`：提交前的场景更新CPU耗时。
- 新 `averageRenderSubmitMs`：`renderer.render`调用CPU耗时，不等于GPU执行耗时。
- 新 `submittedFrames`：实际调用render次数，未除以时间，不作为FPS。

建议同一视角、DPR、设备、工具与皮肤，热身后分别录制静止、30Hz跟随、目标突变、围栏红色闪烁、残影及胶囊体开关；比较帧时分布和CPU/GPU分项。视觉复核与真实GPU瓶颈留给主代理，本轮未执行浏览器操作。

## 验证

运行：`node sim/web/scripts/check-scene-performance.mjs`。`--baseline`仅关闭优化断言以便在改前源码采集计数，不会自动重建旧版本。

通过的行为包括：实时关节/TCP变化、同角度下目标点变化仍上传、框旋转而底座固定、实际胶囊体位置/半径/长度、路径扩容释放与缩短后的包围范围、围栏和残影报警闪烁、碰撞颜色解除后恢复选中状态、factory/cyber皮肤切换及白色吸盘材质、用户视角不变且无存储写入、隐藏/恢复/销毁时rAF释放。

`node --check sim/web/src/scene.js`、方向命名离线回归和差异空白检查通过。构建、浏览器观感、真实GPU帧时及用户现场“是否丝滑”未在本任务中验证。
