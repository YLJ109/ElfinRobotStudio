## 常用流程

物体移动：进入摆放，在列表或三维场景中选中长方体、球或圆柱，拖动出现的坐标轴；左上物体属性同步显示 XYZ，松开后保存。点击“三维移动”可以隐藏/恢复坐标轴。拖动期间只做本地预览，保存失败还原服务端位置；失焦、隐藏或指针取消会撤销尚未提交的拖动。此功能只修改仿真场景，不驱动机器人；原重力、漂浮、落地设置不变，开启重力的物体松开后仍会下落。物体移动与点位的 TCP 三维示教互不混用。

录制：进入工艺，开始录制；切到点位或交互控制完成仿真示教；回工艺停止录制并保存。记录的是仿真实际关节与 TCP，不是尚未到达的目标。采样上限 6000 点、最多 20Hz，静止不重复堆点；停止保存前的数据只在内存中。

执行：打开录制或生成模板 → 显式简化至不超过 256 个路点 → 任务验收检查 → 查看当前起点、工具和现场下的报告 → 确认这一次仿真执行。检查有风险、起点/现场变化、计划超过两分钟或已经使用，必须重新检查。编辑保存有修订冲突时保留本地草稿，不自动覆盖。编辑会替换原录制，先导出原始 JSON；修订号不等于保存了完整历史。

键盘：W/S 或上下方向键控制上下，A/D 或左右键控制左右，Q/E 控制深度，空格回中。输入框内不接管键盘。手柄先回到中立位，左摇杆控制平面、右摇杆纵向控制深度；断开、失焦、隐藏页面撤销输入。三种模拟输入只服务于仿真，不能用来操作真机。

配置档案：保存当前服务端白名单偏好 → 比较差异 → 明确应用。档案不是完整工位备份，不包含 IP、Token、自动连接、围栏、工具、关节限位或真机速度。恢复仅在仿真空闲且未连接真机时允许，当前状态变化需重新比较。

## 尚不能据此宣称

- 擦拭模板不是接触力控；搬运/码垛是几何轨迹，不等于真实夹持或物料仿真。
- ArUco 输出为像素，不是毫米机器人坐标。未完成相机内参与外参标定，不开放视觉自动抓取。
- 新增程序调试、工艺与模拟输入不开放真机执行；旧真机通路保留既有许可、时效与停止闭锁。
- 离线行为测试不代表 GPU 帧率、实际摄像头识别率或真机轨迹与停止距离认证。
- 浏览器连接创建页面失败，真实画面与三维拖拽交互仍需浏览器验收；不把编译通过冒充视觉通过。
