# 玖枢 · JiuShuRobotStudio

玖枢是一套面向六轴机械臂的本地工业机器人工作站，英文名称为 **JiuShuRobotStudio**。作者：伊木；学校：福州理工学院。工程目录与现有接口标识保留兼容，不代表学校官方软件。

![NiHao Elfin Robot Studio preview](docs/assets/project-preview.png)

## 项目定位

ElfinRobotStudio 将仿真、点位示教、关节与笛卡尔运动、程序执行、AI 计划、场景编辑、摄像头和真机监控集中在一个本地界面中。仿真模式默认与真机隔离，适合在没有连接机器人时编写和验证程序；连接真机后，界面会显示控制器状态、关节角、TCP 位姿、IO、告警和执行日志。

## 主要能力

### 工业视觉与末端仿真摄像头

摄像头来源已统一为下拉菜单：电脑枚举到的真实设备与「末端仿真相机」二选一。右侧预览显示当前来源，点击「刷新」更新真实设备列表；选择真实设备后须主动开启。后端串行校验来源互斥，条件关闭绑定相机会话，两个视觉窗口不能用旧回执关闭新会话。末端摄像头为原创横向圆头机身、网孔、中央镜组及夹座，横放于安装板朝腕部一面，随J6整体旋转。默认法兰偏移[0,115.1,-24]mm、沿法兰+X取景；镜头与机身共用姿态，画面保留真实场景遮挡。只迁移已知旧默认值，用户自定义安装参数保留。

桌面端进入「视觉 → 摄像头」，可选择真实设备或「末端仿真相机」，并打开独立可缩放的视觉工作窗口。仿真相机随法兰运动，安装偏移、朝向、视场角、分辨率和采样频率可调；GPU渲染同一场景，CPU识别画面中的颜色与轮廓，不把场景物体坐标冒充检测结果。实体地面跟随围栏投影，每侧外扩100毫米，不添加墙面。

工件识别、尺寸定位、标定和方案分Tab。真实相机开启后按当前启用方案自动分析；浮动预览提供画面、来源下拉、状态和开关，完整采集属性位于摄像头Tab。也可导入JPEG/PNG离线验证。

未标定只显示像素；平面定位需4个拟合点及2个独立复核点，限定当前相机会话、分辨率和视角。移动末端或改变成像参数使旧标定失效。高度是用户指定的代理厚度，不是测量值。启用映射后仅在纯仿真显示独立半透明代理，不写场景物体、不影响碰撞、不授权机器人抓取。真实镜头畸变、手眼标定、现场精度和真机抓取尚未验收。

### A/B料区与场景玩法

「功能 → 井字棋」布置A原料区、B放料区及5个空心O、4个X棋子。你执O先手、电脑执X；选格后生成并预检机器人取放程序，主动确认后由机械臂依次搬运双方棋子。「功能 → 分拣」默认红绿蓝各3个工件，每色可设0—9、总数1—27；按颜色或形状生成取放程序。棋子、料区也在场景物体库中，可用原三维坐标轴拖动。

程序沿用运动与停止链路：等待位→A正上位→A取料位→吸气→A正上位→B正上位→B放料位→停止吸气→破真空→停止破真空→B正上位→等待位。9件对应A18点、B18点及1个等待点；点位表和可编辑ElfinScript同页显示，编辑后须重新预检。吸附期间同一物体随工具运动，释放才提交料位；停止时若仍吸气则保留持件，可在停止状态显式释放。手动重置物料回A是场景复位，不是机器人回搬作业。

一次只有一套任务模板，布置时替换带任务标记的旧模板，保留普通场景物体；需静止、无真机的仿真会话，选择双吸盘参考工具。完整路径经过IK、限位、地面及碰撞检查，失败不执行；定制障碍物和人工移动料区可能使程序不可行。计划绑定场景及起始状态，过期或变化需重新预检。此自动取放仅用于仿真，不猜真实DO映射、不开放未经资格验证的真机笛卡尔轨迹；尚未通过真机抓取验收。

本轮按 Tab 分类的新增功能及边界见 [分类增强使用说明](docs/enhancement-usage-2026-10-27.md)：键盘/手柄交互、三维示教、工艺录制与模板、仿真单步断点、场景批量工具、配置档案及 ArUco 像素检测。新增运动功能仅用于仿真，不表示已经通过真机现场验收。

场景物体库、三维移动、跟随连续求解、AI 同消息计划与 ElfinScript 语法见 [本轮修复说明](docs/scene-ai-follow-2026-10-27.md)。场景预设为本地原创组合几何，使用保守碰撞代理；AI 的聊天文字不等于动作授权，计划必须经验证和主动确认。

- 六轴关节运动与笛卡尔 TCP 运动仿真
- FK/IK、限位、围栏、自碰撞、地面和摆放物碰撞检测
- 点位保存、改名、残影预览和直接执行
- 中英文程序指令、Python 风格循环/判断/函数、代码补全和程序库
- 程序解析、启动、暂停、继续、停止与执行回执
- AI 自然语言计划生成与人工确认执行
- 多工具模板：无工具、两指夹爪、吸盘，并预留工具 IO 映射
- Intel RealSense / 普通 USB 摄像头枚举、选择、彩色流和深度流接口
- 本地事件日志、状态栏、回放和设备诊断
- 无摄像头鼠标模拟：在手掌跟随页选择“鼠标模拟”，控制板映射左右上下，滑条映射前后；仅仿真，沿用工作区、碰撞与停止检查。
- 仿真跟随输入离开时平滑回中心等待：鼠标移出控制区或未检测到手掌不自动取消跟随；重新输入可继续。真机丢掌仍停止，不自动回中。

## 示教与性能反馈

- 三维示教、点位预览及“存目标值”共用会话内目标状态：求解中、等待预览、可执行、执行中、失败或失效。工具、TCP、模式、连接或会话变化后需要重新预览；刷新不会恢复运动授权。
- 三维示教可选固定姿态或自动姿态。自动姿态只用于未连接真机的仿真，求得的 A/B/C 会实际显示；求解失败、计算超时与几何可证明不可达分别反馈，不用旧解冒充新目标。
- 在“系统 → 遥测 → 性能”查看请求、逆解、状态处理与场景 CPU 耗时。样本仅存本机内存；p95 和最大值用于定位卡顿，不代表 GPU 帧率或真机实时性。
- 真机接入前按 [现场验收记录](docs/real-hardware-acceptance.md) 核对身份、TCP、工具负载、速度、停止及断线恢复。当前未连接真机，离线通过不等于现场安全验收。

## 快速启动

Windows：

```bat
start.bat
```

默认打开独立桌面窗口，不再自动打开网页，也不在每次启动时重新构建。优先使用 `output/desktop-release/win-unpacked/JiuShuRobotStudio.exe`，没有打包产物时使用已安装的 Electron 开发运行时。首次需要先准备前端构建。

桌面发布构建：`npm install`，安装 `desktop/requirements-build.txt` 后运行 `start.bat package`。安装器输出到 `output/desktop-release/JiuShu-Setup-1.0.0.exe`；当前未配置代码签名证书。安装后的后端数据和日志保存在当前用户的应用数据目录，不写入安装目录。启动检查等待真实后端、首帧状态和模型完成，不伪造进度。关闭走已确认停止流程，启动期间也允许取消。

「功能」页集中交互、井字棋和场景分拣。井字棋为本地电脑对弈；分拣仅整理所选 100mm 以内小工件的仿真位置，不控制机器人抓取。场景物体创建、编辑、三维拖动和旧现场载入均限制底部不低于地面，重力关闭或悬浮也不允许穿地。

桌面后端诊断日志最多保留 3 个文件（每个 5MiB），待写队列最多 256KiB；超量输出会明确记录丢弃字节数，不让诊断日志无限占用内存与磁盘。源工程原有审计日志策略不受此规则替代。相机状态查询只检查 SDK 安装信息，实际扫描和打开时才加载 SDK。三维渲染继续使用 GPU，手掌推理继续使用 CPU。

资源管理检查参考 [Electron 官方性能指南](https://github.com/electron/electron/blob/main/docs/tutorial/performance.md)和 [Three.js 官方资源释放说明](https://threejs.org/manual/pages/how-to-dispose-of-objects.html)。60 轮原生窗口切页测试用于发现短期保留增长与三维资源计数异常，不代表小时/天级负载、真实相机或真机现场验收。

开发模式：

```bat
start.bat dev
```

手工启动后端：

```powershell
.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8710
```

前端构建：

```powershell
cd web
npm install
npm run build
```

打开 <http://127.0.0.1:8710>。

普通启动会复用健康的后端；前端输入未变时直接复用现有构建，不需要每次打包。
`start.bat build` 强制构建，`start.bat restart` 显式重启本项目后端，
`start.bat stop` 停止经归属核验的本项目后端。无法核验归属的占用进程不会被自动结束。

## 安全边界

首次默认启动为仿真模式。操作者可在驱动页连接真机并选择保存“开机自动连接真机”；已启用该选项时，后续启动会自动重连。真实控制器 IP、API 密钥和运行日志不应提交到公开仓库。请复制 `.env.example` 为 `.env`，再填入本机密钥；不要把 `.env` 上传到 GitHub。

本机访问也校验 Host，避免 DNS 重绑定。局域网/反向代理必须在
`HUYAN_ALLOWED_HOSTS` 显式列出工作站域名或 IP，远端请求还需 `HUYAN_TOKEN`。
令牌仅通过 `X-Huayan-Token` 请求头传递，不再接受 URL 查询参数，避免写进访问日志。
远端浏览器部署需可信 HTTPS 反向代理为 HTTP 和 WebSocket 上游注入该请求头；不要把密钥写入前端构建。
后端启动时会获取本机数据目录的操作系统排他锁，重复进程会拒绝启动；正常退出或进程结束自动释放，
不要手工删除 `backend/data/control.lock`。该锁不替代多主机控制权管理，不要横向复制带硬件控制权的实例。

真机运动前必须确认机械臂周围无人、急停可用、工具和负载已核对，并按现场安全规程进行低速单步验证。项目中的仿真结果不能替代现场风险评估。

## 硬件与数据来源

当前模型针对华沿 Elfin E05-1195_Pro，关节限位、URDF、正逆运动学和控制器协议资料保存在 `docs/`、`_pd/` 与 `huayan-ros2-docs/`。未经现场验证的控制器指令和末端工具 IO 映射会在界面中明确标记。

真机由本系统现有连接与控制通道接入，不需要另做控制软件。连接后，系统在反馈有效、未使能、静止且命令队列空闲时自动只读查询 `PackageVersion`；结果随状态中的 `real.controller_info` 和 `/api/real/hand-follow/status` 返回。读取失败显示未知，不猜版本、不循环重试，也不会自动使能或运动。已使能时延后查询，不自行去使能。README没有记录本机实际版本，协议手册的V6或SDK版本不等于现场软件版本。

已接入真机低速点动兼容跟随：复用既有 `MoveRelJ`，单步不超过0.25°，一次一条，必须收到新的到位反馈才发下一步。需手动连接和就绪、控制器实际倍率不高于5%、实际末端已在框内，并确认无工具；暂不支持未知/未建模真实工具。启动保持当前姿态、不自动居中；丢掌或异常停机，需手动重新开始，刷新不续跑。会有逐步停顿，不是Servo，也不保证与仿真同轨迹。代码与假设备回归通过，尚无真机现场资格验证；不可据此宣称安全认证。Servo连续随动仍未开放。详见 [真机随动接入记录](docs/real-follow-commissioning-2026-10-27.md)。

## 开发与验证

项目采用Electron桌面壳与Vue工作站，统一入口为 `start.bat`，默认不打开浏览器。PyQt 桌面面板已移除。
目录中的仿真和真机是业务模式，不再用 `sim/` 包装整个项目。

后端依赖：`python -m pip install -r backend/requirements.txt`；
相机附加依赖见 `backend/requirements-vision.txt`。首次启动默认不连接硬件。

前端检查：在 `web/` 执行 `npm test` 和 `npm run build`。
后端检查必须通过 `python tools/run_offline_checks.py`，在临时副本执行；
禁止直接在有真实数据的工作站导入测试入口。新增结构检查：
`python -B tools/check_project_layout.py`（只读，不导入控制器或运行 World）。

依赖文件固定了本轮直接依赖版本，不代表完整供应链审计或安全认证。
统一离线验收入口：`powershell -File tools/check_project.ps1`，顺序执行结构检查、
前端回归、构建和隔离后端检查。不会安装依赖、连接硬件或上传结果。
