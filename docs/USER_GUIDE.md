# 用户文档

本页说明已有操作路径；当前版本的测试、界面验收与未验范围见[STATUS](STATUS.md)，仿真通过不授予真实设备资格。

## 当前可以做什么

| 页面/功能 | 当前用途 | 注意 |
| --- | --- | --- |
| 控制 | 单层分类查看状态、连接与就绪入口 | 断线或状态过期显示未知，真机仍需现场资格 |
| 点位 | 关节/笛卡尔目标预览、保存与明确执行 | 笛卡尔输入不是保证直线；自动姿态仅离线仿真 |
| 有趣/跟随 | 手掌、鼠标、键盘、手柄输入 | 共用控制核心；非所有输入都具备真机资格 |
| 有趣/井字棋 | 仿真机器人为双方落子 | 随机先手，O先行，执行后才轮到下一步 |
| 分拣/实用任务 | 视觉找物、计数检查、配套装盒、图案拼摆 | 前两项只读识别；后两项仅仿真且须完整预检 |
| 分拣 | 仿真视觉取放与程序预检 | 需要当前有效识别和标定，人工确认后执行 |
| 场景 | 预设/受控GLB、移动旋转缩放、撤销重做、保存载入 | 导入先检查单位、尺寸、来源和许可，锁定物体需先解锁 |
| 视觉 | 选来源、预览、颜色/轮廓识别、平面标定 | 有效相机/图像来源清楚，代理高度不是测得深度 |
| 程序 | 编程、语法参考、预检与执行 | 复制、载入编辑器、预检和执行是不同动作 |
| AI | 聊天调用、规则整理和本地辅助 | 配置不等于模型可用，聊天不掌握完整现场状态 |
| 系统 | 工具、IO、日志、遥测、设置 | 按当前回读核对结果；失败按原因处理，不反复启动 |

## 连接与显示

连接、断开和模式切换统一在“控制”页对应分类操作；设置页的“前往驱动”只导航，不连接设备。关于页的状态复核也不建立连接。先核对目标与权限，连接不等于使能或允许运动。

工程页→显示选择完整/轻量模型，再点“保存下次启动画质”；只影响下次启动，不刷新当前画面、不打断任务。未保存时可取消修改。

## 点位与残影

1. 选择目标来源，编辑关节或XYZ/姿态。
2. 等待有效求解与后端确认，核对残影和预检结果。
3. 只有明确执行才运动；求解失败不能把旧残影当新目标。
4. 仅查看点位时不应自动收残影；执行后达到正确反馈与停稳条件才确认。
5. 目标或模式、工具、连接变化后需重新预览；已到达的计划不能再次执行。真机逐轴兼容路径不保证笛卡尔直线，不能根据终点残影猜中途路径。

## 四种交互输入

手掌、鼠标、键盘和手柄共用跟随控制。启动目标的 J6 为 0，开始前须完成原有运动预检；关节限位不包含 0 时不能启动。之后按位置优先跟随，开启姿态控制后再跟随输入角度。输入过期、断流或停止后，旧输入不能恢复运动。

“恢复初始范围”明确恢复中心[0,-400,700]、尺寸[800,300,500]、正面270°，不覆盖已保存的用户默认。切换朝向保持世界中心坐标，必要时受当前围栏约束。

点位的左右吸盘各有吸气/停止吸气、放气/停止放气两个按钮，共四个；按有效回读切换，未知或忙碌不发送冲突动作。

## 场景与名称

物体库选类型添加，属性面板改名、位置、旋转或等比缩放；打开移动轴后拖动，松开提交。锁定后先解锁才能编辑。失败保留草稿并显示原因；例如缩放后穿地，应先抬高位置。普通物体可撤销/重做，保存场景后可重新载入。
受控GLB先检查单位、尺寸、来源和许可，再预览、确认导入；坏文件或超预算不能确认。支持自包含静态资源，不保证任意模型、外链、贴图或动画可用。载入场景会改变物体与任务，请先核对。

## 井字棋与分拣

井字棋先布置5O4X，启动对局随机分配O/X，O先走。用户选格后等待机器人完成，不能忙时连点。离页取消保留已确认棋步；查看当前任务状态后再操作。
分拣先布置乱序物料，采集A区并完成识别/标定，再生成、预检和确认。确认所用速度、高度和等待位；实际取放确认后才累计成绩。
“普通场景整理”只改变普通物体位置，与机器人取放不同。重置物料回A不是机器人把物体搬回。

## 四项实用任务

在功能页选择“视觉找物”“计数检查”“配套装盒”或“图案拼摆”。它们使用有限的红绿蓝颜色和平面轮廓识别，不是通用物体识别或工业质量保证。

**视觉找物与计数检查**：先到视觉页手动采集并核对当前来源。选择名称、颜色或形状；需要限制范围时展开“检查区域”，左/上/宽/高用0～1的画面比例，区域不得越界。点一次“查找目标”或“检查托盘”即可完成本次只读检查，不移动机器人。计数可填0～50的预期数量；做错位检查时，每行填一个已标定平面上的 `X,Y` 毫米格位，容差为0.1～100毫米。核对缺件、多件、错位或多目标提示；结果过期、换源或标定变化后重新检查，不沿用旧结果取放。

**配套装盒与图案拼摆**：

1. 填写1～5行列及每格颜色/留空；拼摆也可选现有数字或字母后点“填入图案”。
2. 点“按配方布置物料”，在系统确认框核对后继续。此操作替换任务物料和夹具、保留普通物体，不开启相机或运动。图案A需要10件红料，系统按数量使用38毫米小工件。
3. 到视觉页手动采集A区、完成或重新核对标定，取得新鲜识别；布料后不要沿用旧画面。
4. 返回任务页点“预览格位”，核对物料与目标，再点“预检完整路径”。未知形状、物料不足、格位容量不足或路径不可达均不执行；不是所有场景都可达。
5. 预检成功后，勾选本次执行确认，再点“执行取放”。修改配方、来源或现场后需重新预览、预检，旧计划不能重复执行。
6. 点“取消”保留已确认数量与物体实际位置，不把部分完成记为全部成功。若仍持件，先确认停止，再到末端工具页使用停止吸气/释放仿真持件的正式入口，整理或重新布料；不要直接拖动持件冒充恢复。

## 相机与识别

刷新列表不等于开启；选择来源和开启是不同操作。仿真相机与真实设备不能混为一谈。
未开启检测时默认本地预览，不上传视频或运行后端推理。开启设备需用户授权；切源、断流与退出应释放资源。手机/远程来源还需要可信HTTPS与配对，实际跨机环境另行核验。
远程相机区选择“工件颜色与轮廓”后生成一次性配对码，在可信HTTPS相机页输入并主动授权上传。远程设备保留本地预览，工作站只接收一次视频做颜色/轮廓检测；视觉页可查看、标定，并用于只读找物和计数。远程结果不允许机器人取放：接收时间和跨机时钟估计不能证明真实采集时间。撤销、超时或重新配对会使旧来源/标定失效，不自动恢复运动许可。本机合成视频互通不代表手机、真实相机或跨机网络已验。

现有识别是颜色/轮廓；未标定显示像素。平面坐标依赖当前相机会话/视角，改变成像或相机位置需重新核对；不声称已经完成真实手眼标定。

程序页“语法”分类显示正式语法参考；读取语法不会执行程序。分拣页不提供直接改坐标的假整理入口，取放任务必须经机器人实际完成。

工艺录制入口已按用户要求移除；旧工艺收藏转到程序编辑器。已有录制数据保留，只读恢复/导出不执行机器人；扫描和搬运可使用现有程序语言。

## AI使用

明确点位、速度、等待等走本地白名单整理。每条回复标明“本地规则”“模型回答”或“未生成回答”；规则生成的动作是待人工确认草稿。本地诊断和文本比较不调用模型。模型未配置、已配置未验证、最近请求成功、连接失败、限流和响应无效分别显示；密钥存在不证明可用，不会自动自检。

需要模型解释时，须本轮勾选允许发送当前要求和最近6条对话；默认关闭，发送后复位，不自动附带点位、场景或完整日志。请勿在对话中粘贴凭据。未授权时仍可使用本地规则，不会调用外部模型。

缺少参数时会显示待补充版本。点本条“补充本次要求”再明确填写速度、点位或等待；其他变化用“完整要求：”重述全部动作。有效期120秒，补充不续期；取消、过期或现场变化后重新提出要求。补充只生成新的完整计划，不能用“确认”复用旧许可。

AI上方两个按钮统一提供执行/停止、暂停/继续；仿真计划可直接点击执行，不需重复勾选。真实设备仍须逐条核对工具、IO、路径和环境并完成必要确认。历史回答、复制代码和载入编辑器均不执行；模型聊天不能直接生成执行许可，也不能自动修复源码、猜接线或启动真机。

## 状态、诊断与版本证据

状态栏显示当前控制方、任务阶段及已确认步数；状态未知不代表已停止。启动条件中的定位入口可打开对应设置或诊断，处理后按当前回读重新检查，不能跳过门禁。

系统→遥测→性能复用本地性能统计。保持同一场景、工具、检测来源和版本，点“采集前样本”→“结束采样”，再采集后样本并结束，最后“导出对比”。每秒采样、最多120条；离页、隐藏或条件变化会停止本次采样。输入率、推理率与可信帧龄不等于物理相机或显示帧率；未测的GPU、进程占用等保持未测。采样不启动相机或检测。

系统→关于→更新/验证查看逐功能状态、适用版本、证据与未验项。没有匹配当前版本的清单时会明确提示缺失；历史证据不能证明当前源码或真实设备已验。最终同版截图和综合负载是否完成，以STATUS为准。

YOLO等识别扩展、记忆/顺序挑战与轨迹创作仍为候选，不按已存在功能使用。

## 遇到问题

停止反馈未知时保持闭锁，不用重复启动“试试看”；记录时间、模式、操作、错误与计划ID，不发送凭据。
不要用强制刷新、关闭服务或释放吸盘代替安全停止。恢复策略见[操作指南](ROBOT_OPERATIONS.md)和[运维](OPERATIONS.md)。
