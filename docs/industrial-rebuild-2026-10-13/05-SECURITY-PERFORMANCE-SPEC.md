# 05 安全、性能、可靠性与运维规范

## 1. 三类安全边界

1. 机器人应用安全：真实工具/负载/工件、碰撞、停机、护栏、气路、电气、机械安装和工艺风险。
2. 网络与软件安全：访问控制、攻击面、输入、状态、数据、AI、供应链与更新。
3. 工程证据：风险评估、适用标准、验证和现场交付。

Web按钮、Python超时和3D包络均不承担安全PLC或控制器安全功能等级。软件可请求停止与阻断新指令，但硬件安全回路独立设计、现场确认。[ISO 10218-1:2025](https://www.iso.org/standard/73933.html)、[ISO 10218-2:2025](https://www.iso.org/standard/73934.html)

IEC 62443用于梳理工业控制系统全生命周期的组织与技术安全要求；本方案参考其方向，不声称具备某个安全等级或通过认证。适用地区、系统范围和条款需要项目安全人员确认。[IEC 62443 介绍](https://syc-se.iec.ch/deliveries/cybersecurity-guidelines/security-standards-and-best-practices/iec-62443/)

## 2. 威胁模型

| 资产/入口 | 风险 | 控制 |
|---|---|---|
| 本机控制口 | 恶意网页跨站请求/订阅、Host欺骗 | 回环绑定、Host/Origin完整校验、会话与CSRF策略 |
| 局域网 | 未授权控制、盗取token、控制权争用 | 显式启用、认证、TLS、设备lease、审计 |
| 设备协议 | 非幂等重复、串口/报文注入、迟到回执 | 命令规格、编码白名单、epoch、结果未知 |
| 用户输入/工程包 | 非法单位、NaN、超大载荷、恶意压缩包 | schema、范围、数量/体积限制、路径与解析隔离 |
| AI输出/检索资料 | 提示注入、编造能力、隐私泄露 | 只生成IR草案、服务端校验、可信资料版本、脱敏 |
| 模型与脚本 | 不可信扩展执行、文件访问 | 资产许可/格式限制、沙箱/进程隔离、无任意代码运行 |
| 审计/数据库 | 删除、伪造、损坏、磁盘满 | 事务、权限、备份、摘要链与外部锚定 |
| 发布依赖 | 漏洞、安装劫持、构建漂移 | 锁文件、SBOM、来源、签名、复现构建 |
| 真机工位 | 未知工具、掉件、碰撞、停止失效 | 工具确认、预检、现场保护、HIL/SAT |

## 4. 访问与控制权

本地单人模式：回环监听、安装时建立本机身份与应用会话、受保护的控制接口，不要求频繁登录。多用户/网络模式：工程账号、查看/操作/配置/维护权限、超时与审计；不引入与用户场景无关的人数限制。

所有运动和配置权限在服务器执行。Frontend disabled仅为反馈，不能作为授权。控制权lease绑定用户/客户端/设备/epoch，支持显示持有者和受控交接。只有一个网关具有设备写入权。

停止对已认证合法工作台会话保持可达，设计独立于正在执行的业务任务和普通队列；会话失效不应把持有者的软件停止操作困在UI。绝不因此开放匿名任意控制。物理急停始终独立。

回环HTTP与网络HTTPS使用独立部署配置；cookie Secure只在HTTPS启用，以免本地接口无法登录。若使用cookie会话，写操作有CSRF与Origin保护；WS验证Origin、票据、会话、连接/消息上限与过期。[OWASP WebSocket 安全指南](https://cheatsheetseries.owasp.org/cheatsheets/WebSocket_Security_Cheat_Sheet.html)

生产禁止reload/dev server，限制API文档访问。反向代理显式信任地址，网关自身不能因多个API worker扩容而多开设备连接。

## 5. 输入与应用安全

- 请求采用严格schemas，extra字段拒绝，finite/长度/数量/枚举/单位校验。
- 模型/轨迹/工程导入限制展开大小、文件数、压缩比，禁止zip-slip、符号链接越界、任意脚本执行。
- 设备地址限定登记网段/allowlist；AI及外设URL不得开放为通用SSRF代理，回环/内网访问按不同用途授权。
- 工程程序是解析过的DSL/IR，不执行Python/JS eval；插件在独立进程或声明式适配器运行。
- Vue不渲染未清洗v-html；AI/日志以文本展示，下载文件名与路径由安全服务生成。
- 硬件报文参数禁止分隔符注入；名称/程序名遵循厂家格式白名单。
- CSP/防嵌入/内容类型等头由实际服务配置，Three资产加载需要最小允许策略。
- 密钥只在服务端受保护配置/OS凭据存储；前端bundle、日志、诊断包、URL不包含密钥。
- CSV防公式注入，导出脱敏按白名单字段；工位坐标/配方可属于商业敏感数据。

## 6. AI安全与质量

模型不能持有机器人写入通道；输出必须经schema、能力、工位、工具、点位、IO、轨迹及执行权限校验。规划缓存与确认绑定冻结revision和有效期。

未知工具、未知IO、不存在点位、未验证MOVEL、格式错误、危险指令全部进入明确拒绝；提示注入不能改变白名单或工作站权限。

建立至少100条初始标注评测：正常工艺、歧义、幻觉点位、错位号、危险请求、工具冲突、资料注入、超时、服务不可用。记录有效计划率与拒绝正确率；安全失败项要求零越权通过，不用总体平均准确率掩盖。

资料检索只使用已标记型号/固件的可信文件。引文可追踪原页/段/版本。故障解读分别显示控制器事实、几何计算、历史关联和AI推测。没有网络/模型时本地控制与程序功能继续可用。

## 7. 性能预算

以下是候选验收目标，并非本轮测得结果。参考环境暂定 Windows 11、6核同级CPU、16GB RAM、可用WebGL2 GPU、1920×1080、单机器人、固定工具/模型场景；M0记录具体硬件、驱动、浏览器、模型大小后冻结测试档案。

| 项目 | 初始目标 | 测量方式/范围 |
|---|---|---|
| 首次可操作UI | 缓存启动≤2s；冷启动≤5s | 服务已就绪、本地访问；3D与UI分开报告 |
| 3D帧率 | 常规场景中位≥55FPS，帧时p95≤33ms | 60s固定镜头/运动、报告p99/最低值 |
| 输入反馈 | p95≤50ms | pointer/key到控件反馈；不是机器人实际响应 |
| 快照查询 | p95≤50ms、p99≤100ms | 本机缓存状态、不包括规划/厂家交互 |
| IK预览 | p95≤100ms，截止250ms | 固定姿态集/工具/计算预算；过期可取消 |
| 规划 | 小轨迹≤2s；复杂请求有进度与上限 | 固定数据集、资源限额、碰撞质量报告 |
| 主循环 | 50Hz时p99计算耗时<10ms | 单调时钟记录迟到/占用；不是硬实时保证 |
| UI状态 | 10–20Hz可配置 | 不和3D刷新或厂家采样频率混为一谈 |
| 遥测趋势 | 1–5Hz按来源/用途 | 原始数据与降采样数据独立存储 |
| 软件撤销 | p99≤50ms | 服务器收到停止后epoch失效；非物理停机时间 |
| 24h稳定性 | 预热后稳定，不持续线性增长 | GC后堆/RSS较基线增幅目标≤10%或100MB，取较大者 |
| 日志列表 | 10万事件分页检索p95≤200ms | 固定磁盘/索引/查询，不一次进DOM |
| 初始代码包 | UI必要JS gzip≤250KB | Three/编辑器/图表按需独立报告；不重复计模型 |

物理停止时间/距离、运动精度、节拍偏差、工具吸附/夹持性能没有通用软件保证值，按实际速度、负载、工具与工位现场测量后写合同验收指标。

## 8. 前端性能设计

高频机器人状态为不可变采样缓冲，3D走非深响应式通道；UI按字段/频率投影，遥测独立。Vue官方建议大结构使用shallowRef/shallowReactive或减少深层响应式开销；具体采用前先量测。[Vue 性能指南](https://vuejs.org/guide/best-practices/performance)

- scene模块分robot/工具/对象/轨迹/拾取/资源/渲染；资源缓存、明确dispose、订阅和requestAnimationFrame取消。
- GLB压缩、meshopt/LOD、可选纹理压缩；碰撞模型不得随视觉LOD变粗而偷偷降低安全质量。
- 不在每个状态帧重建geometry/material；Instancing用于重复工位对象。
- 无活动与后台页面降帧，真实状态仍处理；页面返回时立即显示最新采样，不能重播积压帧。
- 日志/表格虚拟化，图表窗口化，降采样保留极值和缺口。
- 程序编辑器、图表、AI、工程扩展延迟加载；UI已可操作时模型加载有独立反馈。
- WS仅保留最新可替换状态；执行事件不能静默丢弃，以seq补取与快照恢复。

## 9. 后端与数据性能

控制路径无阻塞磁盘、网络AI和长时间求解。计算工作进程有任务截止、取消/隔离、结果revision与资源上限；线程超时不能当作已终止CPU任务。

命令串行队列有数量/年龄上限；停止处理不排在大量普通业务请求后。状态缓存写一次多订阅，慢客户端不阻塞网关。

SQLite事务存工程/版本/动作账本，可靠事件追加与定期归档。记录发送前的intent、发送/回执/观察；宕机后不能确认的任务保留unknown，不重发。

遥测按段写文件与索引，容量/保留期可配置；磁盘压力先降低非关键趋势存储，关键执行/工具变更审计不可无提示丢失。无法可靠记录时拒绝新高影响动作，显示维护原因，停止请求仍处理。

## 10. 故障策略

| 故障 | 状态与动作 | 恢复 |
|---|---|---|
| 数据流断/半断线 | stale/disconnected，撤销运动许可 | 新epoch、完整身份/状态核对 |
| 命令回执丢 | result_unknown，不重试非幂等动作 | 根据实际状态/厂家任务ID核对 |
| 浏览器断线 | 本地网关watchdog；点动lease撤销 | UI重连获取快照，不重发旧点击 |
| 计算超时 | 保留最后有效预览，显示超时 | 新目标/预算，不影响控制线程 |
| 工具反馈丢 | 工具动作未知/失败，禁止当作抓取成功 | 核对工件、气源、实际夹持 |
| AI不可用 | 建议功能降级 | 本地程序与控制不依赖AI |
| DB损坏/磁盘满 | 工程只读/维护模式，明确限制新动作 | 恢复备份或修复，不伪造日志成功 |
| 程序步骤异常 | 按冻结工艺分支/停止，记录上下文 | 只在验证恢复点继续 |
| WebGL丢失 | 2D真实读数/停止可用，提示3D不可用 | 重建资源，检查CPU/GPU泄漏 |
| 网关崩溃 | 作业未知，自动重启后不自动运动 | 读真实状态，重新获得控制权 |

## 11. 审计与可观测性

日志分系统、命令、执行、工艺、工具、标定、安全和性能。每条有timestamp、seq、关联ID、来源、前后状态、结果与必要原始回执摘要。

哈希链检测修改但不能抵御具备写权限的攻击者重算全链；需受保护密钥签名/周期外部锚定、备份和权限配合。诊断报告注明其威胁边界。

指标：连接代次、帧年龄/缺帧、命令RTT、队列年龄/深度、主循环延迟、IK耗时/失败、执行各阶段耗时、stop未知计数、工具误匹配、磁盘/CPU/RSS/GPU、客户端慢订阅。

可观测性系统不能使每帧记录产生更多瓶颈；高频指标聚合，执行关键事件可靠保留。告警有状态机、去重、发生/恢复、持续时间和次数。

## 12. 安装、升级与恢复

统一启动器提供 `start/dev/stop/status/doctor`，显示实例、版本、端口、模式与日志。使用PID/实例ID/启动时间校验，端口被别的软件占用时报错，不强杀未知进程。

生产包离线安装：Python运行时/依赖、构建前端、模型、profile、迁移、许可清单、SBOM、校验清单。默认不开真机自动连接、不安装自动运动服务。

升级先停新任务并核对停稳、备份工程、检查磁盘、验签、迁移副本、验证、再激活；失败回退。数据库不可逆迁移通过旧备份/旧应用恢复，不能只替换exe称完成回滚。

备份范围：工程/程序/点位/工具/标定/配方/审计索引；密钥单独保护。配置已提交事务目标RPO=0（本地持久化条件），遥测初始RPO≤60s，应用恢复目标RTO≤30min；磁盘物理故障仍取决于备份频率。必须实际做干净机器恢复演练。

## 13. 安全与稳定门禁

SAST、依赖审计、secret scan、schema边界、WS/HTTP同源测试、工程包恶意样本、模拟厂家报文、权限绕过、AI注入、随机故障、离线24h/72h运行、恢复演练。

关键/高危漏洞需处理或有明确适用性证据，不以一个audit总数作为合格判据；低风险接受记录条件和复审时间。依赖版本在实施时重新查官方支持/公告，不把当前旧锁文件或“升级最新版”直接当安全结论。
