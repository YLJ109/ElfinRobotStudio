# 项目文档维护

只维护当前有用的信息，不追加聊天流水或每次测试总数。

| 信息 | 唯一职责 |
| --- | --- |
| HANDOFF | 短接手入口、最新关键纠正、恢复方式 |
| STATUS | 当前实现与已知限制；新状态替换旧阶段摘要 |
| TODO | 仅未完成/未验证项；完成后删除 |
| PLAN / project.json | 当前需求、必须/候选分级与关闭条件 |
| Code Wiki / 使用开发手册 | 持续有用的代码、操作说明，按任务读取 |
| output | 原始测试/截图证据；不当作当前记忆自动加载 |

执行：先定位一条问题的真实调用链，再做最小修复与相邻验证；已有适用证据直接复用。先修空间对应/真实行为，不能用目录或文案整理冒充功能修复。

完成报告、过时交接和已被替代方案删除，不另建逐日归档；必要运行约定与未解决问题先留下。删除清单及单一恢复压缩包见 [MANIFEST](archive/MANIFEST.json)。原始失败证据、用户数据、第三方许可及全局 G:/AIMem/ 不在文档清理范围。

并行修改先划归属；写入前比较文件哈希，变化就跳过并重新核对，不覆盖其他智能体。当前由其他智能体维护的状态/待办/计划源，本次清理保持原字节。

检查：`node tools/docs.mjs check`；检索：`node tools/docs.mjs find "关键词"`。检查只验证本地链接、索引与清单，不代表功能或现场验收。
