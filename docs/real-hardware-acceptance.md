## 3. 离线完整操作链判据

| 阶段 | 通过判据 | 失败/失效时要求 |
| --- | --- | --- |
| 示教 IK | FK 生成可达近邻目标；真实 IK 返回满足完整位姿精度的有限六轴值及 `reason_code/solve_ms`；实际关节、运动执行器不变 | 求解失败不发布 joints，不以旧解冒充新解；预算超时不能伪称目标不可达 |
| Preview | 显式登记预览后，只有预览状态改变，没有 MoveJ | 未收到新快照确认或安全状态未知时不能执行 |
| MoveJ | 必须显式点击；发送的 joints 与确认目标一致；仿真执行器及实际轨迹完成 | ACK/accepted 只表示受理，不得提前报到位或自动重复提交 |
| 停止 | 仿真轨迹撤销，后续 tick 不继续旧运动；mock 停止有新反馈屏障 | ACK 后无新鲜停稳帧必须闭锁，不得将缓存空闲帧当作确认 |
| 工具变化 | 真实工具选择路由使 preview、已检查计划及上下文失效；旧计划拒绝执行 | 工具/TCP/负载变化后重新求解、检查及人工确认 |
| 会话与断线 | 前端旧上下文/迟到求解不能重新发布；后端拒绝旧帧/断流下的运动，过期队列不重放 | 重连只恢复读取；不能恢复旧目标执行权限或向新连接重放旧停止 |
| 失败恢复 | 显式重试停止并获得新帧；显式重新求解、预览、确认才可提交 | 不自动清错、重发、连接、使能或重启；保留原错误和阶段日志 |

**接口局限：** 当前原始 `/api/movej` 接收关节数组，不携带示教解 token。回归分别检验前端统一目标上下文与后端已检查计划失效；不能据此声称所有自行构造的关节请求都绑定了某次示教解。测试不修改 gate 来强行通过。
