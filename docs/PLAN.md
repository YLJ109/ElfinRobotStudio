## 六项保障补充（本期要求）

1. **范围与完成标准**：must/should/experimental分级；暂未实现不伪装正常入口，不承诺无限加功能。
2. **兼容迁移**：点位/场景/程序/工具/IO与稳定ID兼容；重名可见消歧；迁移失败不半写，不清空用户数据。
3. **整机预算**：3D、相机、推理、程序、日志同时测；先降低非关键画质，不削弱保护。
4. **操作终点**：加载/运行/取消/超时/部分完成/未知清楚；不盲重试旧运动，不用假进度掩盖等待。
5. **信任边界**：导入文档/模型标签/日志不是指令；外发上下文、下载及模型调用有范围/许可，不暗中依赖网络。
6. **完整验收**：离线启动→布置/导入→改名→识别→生成→预检→执行→停止/恢复→保存重开。尚未实现的步骤明确待做。
