# 玖枢 · JiuShuRobotStudio

本地六轴机器人工作站。一台电脑上完成**仿真演练 → 示教编程 → 视觉联动 → 真机接入**的整套流程，支持 Elfin 系列协作臂（当前主用 elfin5）。

> 项目目录名保留 `ElfinRobotStudio`。当前不是已完成现场认证的工业控制产品，真机可用性以 `docs/STATUS.md` 为准。

---

## 这套软件能干什么

### 1. 仿真与示教
不用连机器人也能把动作跑通。

- **关节 / 笛卡尔示教**：拖动滑块或输入坐标，实时看末端的位姿。
- **三维场景**：Three.js 渲染机器人与工作台，可旋转缩放、复位视角、显示轨迹残影。
- **点位管理**：保存、命名、调用点位；点位记录关节角与 TCP 位姿，可一键回位。
- **仿真工具切换**：双吸盘、笔、自定义工具，几何与 TCP 偏移随之改变。
- **碰撞与围栏**：物体与机器人连杆做真实几何接触判定；落位即拦截（放进机器人里的物体当场被拒），落地会停住而不是穿过去。

### 2. 程序
类似示教器的指令序列，可直接执行。

| 指令 | 作用 |
| --- | --- |
| `MOVEJ` | 关节空间运动到目标 |
| `MOVEL` | 笛卡尔直线（仿真：位姿插值 + 逐点逆解；真机需 MoveLTo 资格） |
| `MOVEL P1` | 直线到已保存点位 |
| `DO` / `WAIT` | 数字输出与等待条件 |
| 循环 / 条件 / 调用 | 由程序规则约束，禁止 import、文件网络访问与 eval |

- **程序编辑器**：语法高亮、错误定位、单步与运行、执行日志。
- **程序库**：保存多个程序，随时切换。
- **运行记录**：每次执行留痕，可回看。

### 3. 有趣
面向演示与教学的四个任务：

| 功能 | 做什么 |
| --- | --- |
| **跟随** | 摄像头看着手掌，机械臂末端跟着手掌在范围内移动。手往左，末端往左。 |
| **追踪** | 装在机器人末端的相机看手掌，画面中心跟着手走（IBVS），末端始终水平朝正面。 |
| **井字棋** | 机器人执子对弈，自动取放棋子。 |
| **绘制 / 写字** | 按图形或文字生成轨迹，落笔绘制；面板内有本地进度显示。 |

### 4. 分拣与组装
面向"看见 → 抓取 → 放置"的任务链：

- **分拣**：按颜色 / 形状 / 尺寸规则挑件放位，支持双吸盘与多工位。
- **搬运闯关**：带关卡目标的搬运任务。
- **配套装盒**：按配方把零件配齐装盒。
- **图案拼摆**：按图案模板摆放多个工件。

### 5. 视觉
- **相机管理**：扫描、选择、开关工作站彩色相机；支持虚拟相机（仿真画面）与浏览器预览。
- **手掌检测**：MediaPipe 独立推理进程（`.venv-vision`），主程序不会因此卡顿；模型在**程序启动时就预热**，不用等第一次点按钮。
- **视觉工作区**：框选识别区域、显示识别点、把识别结果映射到三维场景。
- **标记识别**：ArUco 类标记的检测与定位。

### 6. AI 助手
- 自然语言生成程序计划，确认后载入编辑器或执行。
- 支持多家模型厂商（OpenAI / DeepSeek 等），在面板里配置 Base URL 与 Key。
- 模型上下文**只给点位名称，不给坐标与关节值**，避免编造数值。

### 7. 真机接入
分三层，逐层放宽：

| 能力 | 通道 | 状态 |
| --- | --- | --- |
| 点位 / 关节运动 | `MoveRelJ` 分段（每段 ≤10°） | 已通 |
| 手掌跟随 | `StartServo` / `PushServoJ` 流式 | 代码完整，需现场标定 |
| 笛卡尔直线 | `MoveLTo` | 代码就位，需资格记录才允许下发 |

上表第三行受**资格门**约束：没有一条在本机跑出来的标定记录（直线度、到位时间、停止时间），就不向硬件发直线指令。浏览器、配置文件、环境变量都打不开这个门。

## 快速开始

### 仿真运行（不需要机器人）

```bash
# 后端
backend/.venv/Scripts/python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8710

# 前端（另一个终端）
cd web && npm run dev
```

打开 http://localhost:5173/ 。

只想离线演练、绝不碰真机时，启动前加上禁真机开关：

```bash
HUYAN_NO_REAL=1 backend/.venv/Scripts/python.exe -m uvicorn backend.main:app --port 8710
```

### 桌面版

```bash
npm run pack    # 目录版
npm run dist    # 安装包
```

桌面版挂载 `web/dist` 作为窗口页面，打包前需先 `cd web && npm run build`。

### 依赖环境

| 用途 | 位置 |
| --- | --- |
| 后端主环境 | `backend/.venv`（Python 3.12） |
| 视觉推理 | `backend/.venv-vision`（MediaPipe，被检测 worker 直接调用） |
| 前端 | `web/node_modules` |
| 桌面 | 根 `node_modules`（Electron 45） |

## 项目结构

```
backend/          FastAPI 服务
  core/           运动学、规划、仿真、安全、跟随/追踪、真机协议
  application/    视觉管线、绘制、任务编排
  domain/         契约（围栏、接触、工具动作）
  data/           运行时数据：场景、点位、程序、设置、标定
web/              Vue 3 + Pinia + Three.js
  src/panels/     各功能面板
  src/components/ 可复用组件
  public/         模型、工具、视觉资源
desktop/          Electron 壳
tools/            127 项离线检查 + 构建/诊断脚本
contracts/        前后端共用契约 JSON
vendor_elfin/     官方 URDF（机器人几何唯一来源）
docs/             项目文档
```

技术栈：**FastAPI + Vue 3 + Three.js + Electron**。

## 验证

项目自带离线检查体系，不需要机器人也能跑：

```bash
# 全部 127 项（约 15~18 分钟）
backend/.venv/Scripts/python.exe tools/run_offline_checks.py

# 单项
backend/.venv/Scripts/python.exe tools/run_offline_checks.py check_hand_track.py

# 前端
cd web && npm test
```

必须用 `backend/.venv` 的解释器 —— 系统 Python 缺依赖会造成大量假失败。

## 边界与已知限制

这些不是"待办"，是当前事实，用之前必须知道：

- **仿真通过 ≠ 真机可用**。真机通信与跟随源码存在，不代表当前设备可通；工具、控制器资格、停止行为仍需逐项现场核对。
- **MOVEL 真机通道受资格门约束**，没有本机标定记录不会下发。
- **追踪的末端相机画面尚未接入视觉输入**：现有视觉源是工作站相机。真机上要用"末端相机看手掌"，需先把末端相机接成一路图像源。
- **真机跟随是位置伺服**（J6 固定 0°），姿态由"到中心"那一步定下来，不逐帧控姿态。
- 任意 3D 导入、YOLOE 等仍是候选特性，未实现。
- 项目尚未指定整体开源许可证；公开或闭源发布前需审核协议、模型与第三方许可。

已知缺陷与正式检查入口问题见 [状态](docs/STATUS.md)，不能宣称全项目检查已绿。
