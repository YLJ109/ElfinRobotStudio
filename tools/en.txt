             Chapter 1 Software Introduction

Huayan S.p.A Teach Pendent has an operating software that enables manual operation,
programming, parameter configuration and user monitoring of robots. The user can
control the robot through the function buttons on the operation interface, and enable
the robot to move along the user-specified path and complete the expected actions.
The teach pendant serves as the steering wheel that drives the robot.

There are two ways to access the interface of the display controller software to
operate the robot:

 Through Huayan S.p.A Teach Pendent.
The user can directly operate the robot through the teach pendant; in this case, the
teach pendant only serves as the display of the robot.

 Through different end-effectors.
End-effector refers to personal computers and tablets. Refer to the Appendix for
detailed connections.
Supported end-effector devices are personal computers, tablets and etc., which are
connected to the robot through TCP protocol in B/S mode. Refer to the Appendix for
specific connection methods.

4.8. Hold to Target

After entering the value, press and hold the Hold to Target button, the robot arm
moves towards the target position. After reaching the target position, it prompts to
notify and the robot arm stops moving.

Joint angle input: If the input joint angle is beyond the valid range, the system will
prompt the "Available range" of the axis.

Space value input: Press and hold the Hold to Target button, the system starts to
calculate the target point. If the robot arm cannot reach the target point, the system
will prompt the error "Target point unreachable", and the user needs to re-enter the
value.

If the result of the current input value is normal, and the safety range is exceeded
during Hold to Target, it will prompt "Target pose exceeds Cartesian safety space"
and a reset prompt appears.

 TOOL Mode: After entering TOOL mode, press and hold the Hold to Target
button, and the robot arm will move to the target point in the MoveL motion mode of
the TOOL coordinate system;
 Joint Angle: Enter a numerical value in the joint angle text box, and then press
and hold the Hold to Target button to enable the robot arm's end-effector to reach
the specified target point in the MoveL motion mode;
 Spatial Coordinates: Enter a numerical value in the spatial coordinate text box,
and then press and hold the  Hold to Target  button to enable the robot arm's
end-effector to reach the specified target point through MoveL motion mode;
 Hold to Target: Press and hold the button to enable the robot arm to move to the
target point. If the target point is reached, the robot arm stops moving and prompts
"Target reached"; if the button is released during motion, the robot arm stops as well;
 Synchronization: To synchronize the text box data with the actual position value
of the current robot arm;

4.10. Move to Home

                               Fig. 4.10.1 Move to Home Button

Press and hold the Move to home button, the robot arm moves from the current
pose to the home pose in MoveJ motion mode.

The default home pose is the mechanical zero point. For E-series robots, it is an angle
of 0° for all joints; for S-Series robots, it is an angle of -90° for the 2nd and 4th joints,
and 0° for the remaining joints. The home position can be modified by
Configuration-> Home.

Note: Please pay close attention to any obstacles around the robot arm, as the
robot arm may collide with obstacles during the auto homing. It is recommended
to move the robot arm to a safe position before moving to home.

4.11. Z-axis Align

                    Fig. 4.11.1 Z-axis Align Button

In any pose of the robot arm (except when it is at a singularity point), press and hold
the Z-axis align button, the TCP Z direction of the end-effector tool of the robot
arm will move to an pose parallel to the Z direction of the user coordinates in the
MoveJ motion mode. During the motion, the spatial position parameters (X, Y, Z) and
orientation parameters (RX, RY, RZ) of the end-effector tool of the robot arm will
change. After the motion, the spatial position parameters (X, Y, Z) of the robot arm's
end-effector will be recovered to that before the motion, while the parameters of RX,
RY, and RZ will change due to the pose adjustment of the robot arm.

Fig. 5.2.1 Security Verification

This page configures the installation position and angle of the robot arm. The security
password (consistent with the currently logged in administrator password) must be
verified before operation.

The world coordinate system is a global three-dimensional rectangular coordinate
system, usually referenced by the ground or installation platform, which is used to
describe the absolute position and orientation of objects in space. Its origin is usually
defined at the center of the robot arm base, with the X-axis point to the body cable
directly, the Y-axis on the left side of the body cable, and the Z-axis vertically upward.

When the robot arm is mounted on the ground or on a table parallel to the ground, and
the robot is in an initial pose, the base coordinate system of the robot is parallel to the
Z axis of the world coordinate system.

If the robot arm is ceiling-mounted, wall-mounted or installed at a certain angle, the
base coordinate system of the robot will no longer coincide with the world coordinate
system. It is necessary to determine a new base coordinate system according to the
actual installation mode. Through functions in the interface, users can redefine the
user coordinate system of the robot to match the installation method, thus ensuring
that the robot's motion direction and operating logic are as expected.

The controller uses advanced dynamics models to ensure the smooth and accurate
movement of the robot arm, and enables the robot arm to support itself when it is in
the basic free drive mode. Therefore, the installation angle and position of the robot
arm must be set correctly.

Warning: Always apply the correct installation settings; otherwise, it may cause
accidents, or the robot arm may lose control at the moment of pressing the free
drive button!

5.6. Safety Range

The safety range can be set as a restricted area through plane mode or space mode,
and the robot arm is prohibited from entering. This range further constrains the
maximum space in which the robot arm's end-effector can operate.

When the robot arm's end-effector moves within the safe motion range, if the
end-effector touches the restricted area, the robot arm will stop moving and report an
error. Upon the occurrence of an error, click  Reset  to retract the robot arm's
end-effector and move it back to the safety zone before normal operation can resume.

When the robot arm's end-effector is within the restricted area, the system will
monitor the motion trend in real time:
 Away From Restricted Area: If the end-effector motion trend is far away from the

     restricted area, the robot arm is allowed to continue moving until it enters the
     safety range;
 Deep into Restricted Area: If the end-effector motion trend is deep into the
     restricted area, it will be regarded as triggering the safety space restriction, and
     the robot arm will immediately stop moving and report an error.

Note: Security verification is required before setting.

5.9. Force Sensor

Traditional industrial robots are only capable of position control, limiting them to
simple contact tasks like welding and painting. However, many tasks require

Guangdong Huayan Robotics Co.,Ltd.                           74
                                                                                   Chapter 5 Configuration

interaction with the environment and specific contact forces. This need gave rise to
force control function, which adjusts robot trajectories using contact force feedback
signals.

The Advanced Free Drive Mode is a control mode that allows an industrial six-axis
robot arm to move freely under external forces. Typically used with torque sensors, it
enables human operators or other external forces to directly push or guide the robot
arm without traditional programming or controller input. This mode is mainly used in
programming, teaching and debugging phases, making robot arm operation more
intuitive and convenient.

In Advanced Free Drive Mode, each joint of the robot arm can move freely when
external forces are applied. The control system does not actively apply torque. Instead,
it uses force/torque sensors to detect external forces, calculates the needed drive
current to counteract gravity and inherent resistance. This allows the arm to be easily
moved by hand or other external forces when external forces are applied.

Note: This function requires external forces to be applied directly to the robot
arm's end-effector. As the robot arm only has a force sensor at its end-effector
and none on other parts, the robot arm will not respond and will remain
stationary in Advanced Free Drive Mode if external forces are not applied there.

5.9.1. Advanced Free Drive

The Advanced Free Drive Mode includes position mode, attitude angle mode, free
mode and custom mode, and users can choose according to their needs. The default
displays are location mode and last set mode.

 Position Mode: Only movable along the X, Y, Z axes;
 Attitude Angle Mode: Only movable in RX, RY, RZ directions;
 Free Mode: Movable in X, Y, Z, RX, RY, RZ directions;
 Custom: The user can select one or more positions or rotation angles to move the

     robot arm;
 Compliance: By adjusting the compliance parameters, users can customize the

     damping of force-controlled dragging when enabling the Advanced Free Drive
     mode, thereby optimizing the feel of the operation hand;

Compliance can be classified as translational compliance and rotational compliance.
By setting the total compliance, the user can simultaneously control both translational
and rotational compliance, allowing them to be set to the same value. In contrast,
custom compliance enables users to adjust the parameters of translational and
rotational compliance individually.

6.4.1. If

The conditional command guides the robot arm to perform corresponding motions
based on different conditions. When the If condition is met, the robot arm executes
the motion sequence under the If module. Once execution begins, the robot arm
completes all commands within the If module, regardless of whether the condition
remains true during execution.

condition is true, the robot arm will execute the command in the If module; When the
If condition is not met, it checks each Else If condition in order and executes the first
matching branch. If no conditions match, it executes the Else branch commands.

13.1. Protective Stop

During robot operation, errors may occur, leading to abnormal performance or other
exceptions. To avoid such abnormal conditions, a protective stop is required. A
protective stop is a cessation ("safe stop") triggered by the robot controller when it
detects an error. This warning message will be displayed on the teach pendant or
external monitor to notify the error state. In robotics, protective stops are classified as
follows:

 Class 0 stop, also known as Stop 0: Immediately cut off the power supply of the
motor.

Because the motor loses power during the deceleration process and cannot be
controlled, the robot arm will deviate from the predefined running path, which is an
uncontrolled stop mode. The emergency stop button is implemented by performing
Stop 1 first; if Stop 1 does not take effect within the specified time, Stop 0 will be
automatically started.

 Class 1 stop, also known as Stop 1: The controller controls the motor to slow
down to stop, and then cuts off the power supply.

This is a controlled stop method, and the robot arm basically completes the
deceleration according to a predefined path. In the latest robotic systems, due to the
use of safety controller technology, after the emergency stop button is triggered, the
system prioritizes the execution of Stop 1 stops (except in manual mode) to protect
the braking system. If Stop 1 does not take effect within the specified time limit, the
system will automatically upgrade to Stop 0 stop.

 Class 2 stop, also known as Stop 2: It is completely decelerated through the servo
system. After stopping, the power supply is not cut off, and the motor is still
electrified. It is a completely controlled stop mode. Nowadays, the program stops of
robots all fall into this category.

The current controller software realizes protective stop operations through various
functions, including emergency stop, safety range and collision.

feedback force can also stop the robot.

After stopping, it can be restored to normal by resetting. To be on the safe side, make
sure the robot doesn't hit an obstacle when resetting, so as not to trigger a safe
collision stop again.

13.6. Singularity Point States

"Singularity" is a common robot phenomenon, which is not caused by robot design,
processing, or system defects. It is an inherent characteristic of six-degree-of-freedom
non-redundant robots. Customarily, the configuration where strange phenomena occur
is usually called "singular configuration", also called "singularity point".

Singularity point usually refers to some positions of the robot arm in its workspace,
which will cause some performance parameters of the robot arm (such as velocity,
acceleration, force, etc.) to be discontinuous or infinite. These positions may be due to
the structural design of the robot arm, joint configuration, or characteristics of the
kinematics equation. At the singular position, the robot arm may encounter the
following situations:

A. Infinite Joint Velocity: At some singularity points, in order to keep the velocity of
     the end effector constant, it may be necessary to have an infinite angular velocity
     of a certain joint, which is impossible in practical applications.

B. Infinite Joint Acceleration: Similar to velocity, some singularity points may
     require infinite acceleration of the joint to achieve the desired end acceleration.

C. Infinite Moment: In some positions, in order to maintain the balance of the robot
     arm or generate a certain force, infinite driving torque may be required.

D. Discontinuity of Kinematic Solutions: At some singularity points, multiple
     kinematic solutions may exist for the robot arm, i.e., multiple different
     combinations of joint angles can lead to the same end position and pose. This will
     make it difficult for the control system to choose a stable solution.

E. Range of Workspace: At the edge of the workspace of the robot arm, singularity
     points may also appear, because some joints of the robot arm may have been
     extended to the limit and cannot be moved further. A proper understanding of the
     concept of singularity points is helpful to avoid these unfavorable positions when
     designing and controlling the robot arm, and ensure the stable operation and
     efficient work of the robot arm. In practical applications, engineers will reduce
     the impact of singularity points by optimizing the structural design of the robot
     arm and improving the control algorithm.
